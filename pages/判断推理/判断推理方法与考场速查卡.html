行测判断推理：方法与考场速查卡

覆盖：图形推理、定义判断、类比推理、逻辑判断。
目标：把“凭感觉”改造成“识别题型 → 提取规则 → 验证选项”。
使用方法：正文用于学习；第 1、19、20、23 节用于考场和复盘。

0. 判断推理不是一种能力，而是四种能力

子模块 真正考什么 核心动作
图形推理 从图形变化中发现可重复规则 分类观察、验证规律
定义判断 严格匹配题干给出的临时规则 拆条件、逐项核对
类比推理 判断词项之间的关系是否一致 造句、细化二级关系
逻辑判断 形式逻辑、论证评价与信息排列 翻译条件、找漏洞、列表排除

四类题必须分别记录正确率和用时。定义判断做得好，不代表图推或逻辑判断也好；“判断推理正确率”这个总数字不能指导专项训练。

1. 所有判断题共用的四步法

  1. 认题型：图形、定义、类比，还是逻辑中的翻译、真假、加强削弱、分析推理？
  2. 提取规则：把长题干压缩为图形特征、定义条件、词项关系或逻辑符号。
  3. 先排明显错误：优先用必要条件、主体、范围、矛盾关系排除。
  4. 回题干验证：正确答案必须满足全部要求，不能只符合一部分。

考场底线：

没有说出依据的“看着像”，不算真正会做。

2. 图形推理：先分类观察，再尝试规律

独立导航卡：图形推理分类导航与遍历清单。该卡按“图感直达 + A/B/C/D 分类遍历”组织，适合专项训练和考前快速复习。

2.1 推荐观察顺序

不要把所有规律同时试一遍。先按图形之间的关系选择入口：

A 类：组成相同、位置不同 → 平移、旋转、翻转、位置遍历
B 类：相同元素反复出现 → 遍历、运算、种类数、拆分平移、相邻复现
C 类：整体相似、局部增删 → 相加相减、去同存异、去异存同
D 类：不相同也不相似 → 属性、特殊关系、有依据地计数
立体图形 → 看相邻/相对、公共边、面的位置关系

没有明显感觉时，A/B/C/D 是保底遍历路线；若有强特征，可以直接检查高概率考点，例如多封闭区域先看面、多交叉线先看交点、五角星或日田字结构先看笔画、小黑点或箭头先看功能位置。

D 类内部的默认检查顺序：

  1. 整体属性；
  2. 图形连接、位置关系或功能元素；
  3. 根据显著特征选择一个对象计数。

这只是默认起点，不是每题把全部规律依次试一遍。一个规律至少要解释两组图、覆盖关键元素并导向唯一选项；约 50—60 秒仍无有效路径时标记跳过。

3. 图推：位置规律

适用特征：图形组成元素基本相同，只是位置发生变化。

3.1 平移

观察：

  • 上下、左右、顺逆时针移动；
  • 每次移动固定步数；
  • 步数递增或周期变化；
  • 多个元素分别沿不同轨迹移动；
  • 到边界后循环、反弹或折返。

验证时必须明确：

谁在移动 + 沿什么路径 + 每次几步 + 到边界怎么办

3.2 旋转

观察角度、方向和中心：

  • 每次顺时针/逆时针固定角度；
  • 角度递增；
  • 内外元素方向相同或相反；
  • 多元素轮流旋转。

3.3 翻转

  • 左右翻转：像照竖直镜子；
  • 上下翻转：像照水平镜子；
  • 旋转改变朝向，翻转会改变“手性”。

判断不清时找不对称标志，例如缺口、箭头、字母样元素。

3.4 遍历

一组图中某些位置、样式或元素各出现一次。

常见于九宫格：先看每一行或每一列是否满足“元素种类齐全且不重复”。

4. 图推：样式规律

适用特征：图形轮廓相似，元素存在加减、叠加或区域变化。

4.1 叠加运算

常见规则：

  • 相同保留、不同消失；
  • 相同消失、不同保留；
  • 黑 + 黑、黑 + 白、白 + 白分别产生固定结果；
  • 前两图叠加得到第三图。

不要凭整体印象，要选择一两个对应位置建立运算表，再验证其他位置。

4.2 去同存异与去异存同

  • 去同存异：共同部分消失，不同部分保留；
  • 去异存同：只保留共同部分。

4.3 图形相加或相减

观察线条、封闭区域或小元素是否由前图组合而来。必须验证所有元素，而不是只验证一个局部。

4.4 黑白块运算

先抽取同一位置的三组对应关系，推导规则；若同一输入得到不同输出，说明规则不成立。

5. 图推：数量规律

适用特征：图形差异较大、线条多，看不出位置或样式变化。

5.1 常数、等差、周期和分组

数量列常见关系：

  • 恒定；
  • 递增/递减；
  • 等差；
  • 奇偶交替；
  • 周期变化；
  • 两组分别成规律；
  • 九宫格行列之间相加、相减或求同。

5.2 高频计数对象

计数项 看什么
点 交点、切点、端点、特殊点
线 直线、曲线、线段、笔画
面 被线条完全围住的封闭区域
角 锐角、直角、钝角或角的总数
元素 小图形种类、个数、部分数
封闭区 有几个独立封闭空间

“面”必须完全封闭；线条相交不一定增加面。

5.3 交点细分

若只数交点没有规律，再看：

  • 曲线与直线交点；
  • 内外图形交点；
  • 十字交点与 T 形交点；
  • 图形内部或外部的交点。

5.4 一笔画与奇点

把图形看成点和线组成的连通图。与奇数条线相连的点叫奇点。

  • 连通图有 0 个奇点：可以一笔画并回到起点；
  • 连通图有 2 个奇点：可以一笔画，起终点是两个奇点；
  • 奇点超过 2 个：不能一笔画。

最少笔画数在常见连通图中可用：

奇点数为 0 → 1 笔
奇点数为 2 → 1 笔
奇点数为 2n（且大于 2）→ 至少 n 笔

图形不连通时，各连通部分分别判断后相加。

6. 图推：属性规律

适用特征：图形组成不同，但具有某种整体性质。

6.1 对称性

观察：

  • 轴对称、中心对称；
  • 对称轴数量；
  • 对称轴方向；
  • 同时轴对称和中心对称；
  • 对称轴与图形中线条、点、面的位置关系。

6.2 曲直性

  • 全由直线构成；
  • 全由曲线构成；
  • 直曲混合；
  • 内外图形的曲直关系相同或相反。

6.3 开闭性

  • 全封闭；
  • 全开放；
  • 半封闭；
  • 内外图形开闭性一致或不同。

6.4 凹凸性

  • 凸图形：任取图形内两点，连接线段仍在图形内部；
  • 凹图形：存在向内凹陷。

考试中通常通过直观识别即可。

7. 图推：特殊元素与功能关系

图中若反复出现一个明显的小黑点、箭头、阴影、小圆或短线，它常是“功能元素”，重点看它与主体的关系：

  • 位于内部、外部还是边界；
  • 落在长边、短边、直线、曲线上；
  • 与某条线垂直或平行；
  • 标记锐角、直角或最大区域；
  • 两个点处于同一面、相邻面或相对位置；
  • 功能元素沿轮廓移动。

不要只数功能元素个数，先看它“在标记什么”。

8. 图推：空间重构

8.1 六面体展开图

核心不是在脑中硬折，而是判断面之间的关系。

相对面

相对面在立方体中不能同时出现在同一个可见顶点，也不能共享一条边。

在常见展开图中可用“隔一面”或围绕公共面判断，但不要只背展开图形状；优先标记面并追踪公共边。

相邻面

折叠前共享边的面必然相邻；没有直接共享边的面也可能折后相邻，需要结合公共面判断。

画边法

  1. 给各面编号；
  2. 在展开图和选项中找同一面；
  3. 以该面为基准，按同一方向标记相邻边；
  4. 比较另外两面的相对位置是否一致。

时针法

同一个顶点相交的三个面，按顺时针记录顺序。整体旋转不会改变顺逆时针关系，镜像才会改变。

8.2 截面图

判断一个平面切过立体后可能形成的图形：

  • 截面边来自所切到的表面；
  • 一刀不能凭空穿过没有接触的结构；
  • 先看选项需要切到哪些面，再判断单一平面能否同时经过。

8.3 三视图

  • 主视图：从正面看；
  • 俯视图：从上面看；
  • 左/右视图：从侧面看；
  • 被遮挡结构是否画出，以题目所给规则为准。

空间题超过合理时间仍无法确定公共边，应跳过，不在考场进行长时间想象。

9. 定义判断：把定义拆成条件清单

9.1 四步法

  1. 圈出主体；
  2. 圈出行为、方式或机制；
  3. 圈出目的、原因、结果；
  4. 圈出时间、对象、范围和必要条件。

把定义压缩成：

谁 + 在什么条件下 + 以什么方式 + 对谁做什么 + 产生什么结果/为了什么目的

9.2 必要条件与描述性信息

定义中的信息重要程度不同：

  • “必须、只有、特指、以……为目的”通常是硬条件；
  • 背景介绍或举例可能只是帮助理解；
  • 选项违反一个必要条件即可排除；
  • 不能因为符合一两个显眼词就忽略其他条件。

9.3 正向与反向提问

先圈题干：

  • “属于/符合的是” → 找满足全部关键条件者；
  • “不属于/不符合的是” → 三个符合，一个违背，注意不要选反。

9.4 多定义题

先给每个定义写一个最短标签，再匹配案例。例如：

定义 A：外部刺激导致暂时改变
定义 B：内部机制导致稳定改变

不要在长定义之间来回重读。

9.5 定义题常见陷阱

  • 主体不符；
  • 对象不符；
  • 目的相似但方式不符；
  • 结果相似但形成原因不同；
  • 日常含义符合，但不符合题干临时定义；
  • 只满足例子特征，不满足定义本身。

定义判断只认题干规则，不与题干争论现实中是否合理。

10. 类比推理：先造句，再细化关系

10.1 基本方法

用最简洁的句子连接题干词项：

A 是 B 的……
A 用于……B
A 与 B 是……关系

然后把同一句式代入选项。若多个选项都成立，再比较二级关系。

10.2 高频关系

关系 例子 识别要点
全同 土豆：马铃薯 同一事物不同称呼
并列 苹果：香蕉 同属一个上位概念
矛盾 生：死 非此即彼，无第三状态
反对 红：白 不能同时成立，但存在其他状态
种属 苹果：水果 前者是后者的一种
组成 轮胎：汽车 前者是后者的组成部分
对应 教师：学校 人物、场所、工具等对应
功能 钥匙：开锁 工具与主要功能
原料 木材：家具 原材料与成品
加工 粮食：酿酒 对象与加工结果/活动
因果 暴雨：洪水 原因与结果
顺承 报名：考试 时间或流程先后
属性 盐：咸 事物与典型属性
象征 白鸽：和平 事物与象征意义
主宾 医生：治疗：患者 主体、行为、对象

10.3 二级辨析

初级关系相同后，再看：

  • 必然还是或然；
  • 主要功能还是次要功能；
  • 天然组成还是人为组成；
  • 直接原料还是间接原料；
  • 职业与专属工具还是一般工具；
  • 先后顺序是否一致；
  • 主动与被动关系是否一致；
  • 词语感情色彩和结构是否一致。

10.4 集合关系

  • 全同：A 与 B 完全相同；
  • 包含：所有 A 都是 B，但并非所有 B 都是 A；
  • 交叉：一部分 A 是 B，一部分不是；
  • 全异：A 与 B 没有交集；
  • 矛盾：A 与非 A，覆盖全集；
  • 反对：A 与 B 不相交，但未覆盖全集。

“组成关系”不是“种属关系”：轮胎不是一种汽车，苹果是一种水果。

11. 翻译推理：把汉语变成箭头

设 A、B 分别代表两个命题。

11.1 充分条件

如果 A，那么 B
只要 A，就 B
一旦 A，就 B
A 是 B 的充分条件

翻译为：

A → B

11.2 必要条件

只有 A，才 B
除非 A，否则不 B
没有 A，就没有 B
A 是 B 的必要条件

翻译为：

B → A

技巧：“谁是必要条件，谁放箭头后面”。

11.3 逆否等价

A → B  等价于  非B → 非A

例如：

下雨 → 地湿
地不湿 → 没下雨

不能推出：

地湿 → 下雨
没下雨 → 地不湿

后两种分别是“肯后”和“否前”，形式上无效。

11.4 且、或、要么

  • A 且 B：两者都真；
  • A 或 B：至少一个真，允许两者都真；
  • 要么 A，要么 B：通常表示二选一，不能同时成立；具体以题干定义为准。

11.5 德摩根定律

并非（A 且 B） = 非A 或 非B
并非（A 或 B） = 非A 且 非B

11.6 命题为假的唯一情况

A → B

只有在 A 真、B 假 时为假。

因此：

并非（A → B） = A 且 非B

12. 真假推理

12.1 先找矛盾关系

矛盾命题必有一真一假：

命题 矛盾命题
所有 A 都是 B 有的 A 不是 B
所有 A 都不是 B 有的 A 是 B
有的 A 是 B 所有 A 都不是 B
有的 A 不是 B 所有 A 都是 B
A 非 A

若题目说“只有一句真”或“只有一句假”，先锁定矛盾对，再判断其余命题。

12.2 反对关系

  • “所有 A 都是 B”与“所有 A 都不是 B”不能同真，但可以同假；
  • “有的 A 是 B”与“有的 A 不是 B”可以同真，但不能同假（默认 A 类存在时）。

实际考试优先使用明确矛盾，反对关系用于进一步判断。

12.3 假设法

没有直接矛盾时，假设某句话为真或某人说真话，推导是否满足题目给定的真假数量。

一旦出现矛盾立即回退，不需要把所有分支推完。

13. 加强论证

13.1 先拆论证

论据 R → 结论 C

问自己：从 R 到 C 中间缺了什么？结论是否还有其他解释？样本能否代表总体？

13.2 常见加强方式

按常见力度理解，而非机械排名：

  1. 建立联系/搭桥：证明论据与结论之间确实相关；
  2. 补充必要前提：没有它，论证无法成立；
  3. 排除他因：排除其他因素造成结果；
  4. 增加正面论据：提供新数据、机制或案例；
  5. 加强样本代表性：说明样本足以代表总体。

具体力度取决于论证漏洞，不是“搭桥永远最强”。

13.3 前提型问法

上述论证成立必须基于哪项前提
哪项是论证成立的必要条件

可用否定代入：把选项否定后，若论证无法成立，该项更可能是必要前提。

注意：否定后只是让结论变弱，不一定就是必要前提；应达到论证链条被切断的程度。

13.4 无关项

  • 只解释背景，不连接论据与结论；
  • 讨论另一个主体或指标；
  • 只是重复结论，没有新支持；
  • 同时带来相反影响，方向不明确。

14. 削弱论证

14.1 常见削弱方式

  1. 切断联系：论据不能推出结论；
  2. 因果倒置：不是 A 导致 B，而是 B 导致 A；
  3. 另有他因：B 由 C 导致；
  4. 否定原因或结果：事实与结论相反；
  5. 反例：存在符合论据却不符合结论的情况；
  6. 样本不代表总体：样本偏差、数量不足或选取不随机；
  7. 措施达不到目的：对策不可行、有副作用或作用对象不匹配。

14.2 因果论证优先检查

时间先后是否被当成因果？
相关关系是否被当成因果？
是否存在共同原因？
是否可能反向因果？
对照组是否可比？

14.3 削弱力度

直接针对核心论证链的选项通常强于只说“情况复杂”“还需研究”。

“存在例外”能否削弱取决于结论强度：

  • 结论说“所有、必然”：一个有效反例即可强烈削弱；
  • 结论说“通常、可能”：个别反例力度有限。

15. 解释与评价型论证

15.1 解释矛盾

题干给出两个看似冲突的事实，正确选项必须让二者能够同时成立。

步骤：

  1. 写出冲突两端；
  2. 找到隐藏的时间、主体、口径或中间机制；
  3. 选能同时解释两端的选项。

只解释其中一端不够。

15.2 评价论证

问“哪项问题最有助于评价”时，看不同答案是否会让论证变强或变弱。

如果无论回答“是”还是“否”都不影响结论，该问题无关。

15.3 论证结构相似

先抽象题干形式：

所有 A 是 B；C 是 A；所以 C 是 B

再比较选项结构，不要被具体题材干扰。

16. 分析推理：列表、排除和确定信息优先

适用于人员、位置、时间、分组、比赛和匹配安排。

16.1 四步法

  1. 明确对象和位置/组别；
  2. 把条件简写；
  3. 从确定性最高的条件开始；
  4. 结合选项代入或排除。

16.2 条件简写

A 在 B 前：A < B
A 与 B 相邻：AB / BA
A、B 不同组：A ≠ B
A 在第 3 位：A = 3
若 A，则 B：A → B
A、B 至少一人：A 或 B
A、B 恰有一人：A、B 二选一

16.3 从确定信息入手

优先级通常是：

  1. 唯一位置或确定分组；
  2. 必须相邻、必须前后；
  3. 互斥和容量限制；
  4. 条件命题；
  5. 模糊范围条件。

16.4 最大信息原则

选取与其他条件关联最多的对象作为突破口。例如 A 同时出现在三条条件中，先围绕 A 整合。

16.5 选项代入

以下问法优先考虑代入：

  • “可能为真”；
  • “不可能为真”；
  • “以下哪项安排符合”；
  • 条件多但选项给出完整方案。

代入时先检查最严格、最容易违反的条件。

16.6 假设法

当题目有二选一条件或某对象只有两个位置时，分两种情况讨论。每个分支一旦矛盾立即停止。

17. 集合与数量关系型逻辑

17.1 至少、至多和恰好

  • 至少一个：大于等于 1；
  • 至多一个：小于等于 1；
  • 恰好一个：等于 1；
  • 至少两个：大于等于 2。

17.2 容斥基础

两集合：

|A∪B| = |A| + |B| - |A∩B|

至少都满足的下限：

|A∩B| ≥ |A| + |B| - 总人数

最小例子：100 人中 70 人会游泳，60 人会骑车，至少 70 + 60 - 100 = 30 人两者都会。

17.3 “有的”的含义

逻辑中“有的 A 是 B”表示至少一个，不表示只有一部分，也不排除所有 A 都是 B。

从“有的 A 是 B”可换位为“有的 B 是 A”；但“所有 A 是 B”不能直接推出“所有 B 是 A”。

18. 高频干扰项

类型 表现 检查动作
肯后错误 A→B，B，所以 A 只能逆否，不能肯后
否前错误 A→B，非A，所以非B 否前不能推出结论
条件倒置 把必要条件当充分条件 看“只有/只要”
偷换概念 结论中的词与论据含义不同 对照核心概念
样本偏差 小样本或特殊群体推总体 查代表性
相关当因果 同时变化就说互为因果 查他因、反向因果
诉诸个例 用一两个案例证明普遍规律 看结论范围
定义漏条件 只满足显眼词 列必要条件清单
类比层级不同 都有关联但关系粗细不同 比二级关系
图推过拟合 规律只能解释部分图形 必须验证全部图形

19. 看到题型，立刻执行什么

题型 第一反应 最后检查
图形相似 位置、旋转、翻转、叠加 规律能否解释全部图形
图形凌乱 数点线面、封闭区、属性 计数口径是否一致
功能元素明显 看小点/箭头与主体的关系 不只数个数
六面体 找相对面、公共边、三面时针 是否发生镜像
定义判断 拆主体、条件、方式、目的、结果 是否漏掉硬条件
类比推理 造句确定一级关系 二级关系是否同层级
“如果/只要” 翻译 A→B 只能推出逆否
“只有/除非” 必要条件放箭头后 不要翻译反
真假话 先找矛盾对 真/假数量是否满足
加强 拆成论据→结论，找缺口 是否真正连接核心链条
削弱 查因果、他因、反例、样本 是否只说“情况复杂”
前提 否定代入 否定后论证是否崩塌
解释矛盾 同时解释冲突两端 不能只解释一端
排列组合 列表、确定信息优先 是否满足全部条件
可能/不可能 优先代入选项 先查最严格条件

20. 考场顺序与止损

默认将判断推理整体控制在总计划的 30 分钟时间盒内，子题型顺序按个人数据决定。启动期可先测试：

定义判断 → 类比推理 → 图形推理 → 逻辑判断

理由：定义和类比通常启动快；图推和长逻辑题波动更大。但如果你的数据表明逻辑或图推明显更强，可以前移。

单题启动期参考

子题型 参考时间 止损条件
类比推理 30—45 秒 两轮关系仍无法区分，标记后走
定义判断 40—60 秒 反复重读定义仍说不出硬条件，走
图形推理 40—60 秒 默认入口无规律，换一次角度后仍无结果，走
翻译推理 45—70 秒 条件已翻译但无法推出，检查选项后走
加强削弱 50—80 秒 无法说清论据和结论，先标记
分析推理 60—100 秒 画表后仍无确定信息，优先代入；仍无进展则走

两轮作答

第一轮：

  • 定义条件清楚、类比关系明确的题；
  • 能快速识别规律的图推；
  • 一步翻译、直接逆否的逻辑题；
  • 加强削弱中漏洞明显的题。

第二轮只回收：

  • 图推已经排除两项且有一个候选规律；
  • 定义题只差核对一个条件；
  • 逻辑题已经完成列表或条件翻译；
  • 加强削弱二选一且能说明力度差别。

不回收完全没有入口的图推和需要重新从头列表的长分析题。

21. 专项训练顺序

  1. 定义判断：先练拆条件；
  2. 类比推理：建立关系词典；
  3. 翻译推理：充分、必要、逆否、且或；
  4. 加强与削弱：拆论据和结论；
  5. 图形推理：按位置、样式、数量、属性分组；
  6. 分析推理：列表、代入、假设；
  7. 混合组卷：训练题型切换和时间盒。

每个子题型至少用一组约 10 题记录：正确率、平均用时、无依据做对数和主动放弃数。

图推错题不要只贴原图，应写：

我为什么没想到这个观察入口？
这个规律有哪些显著图形特征？
我尝试的错误规律为什么不能解释全部图形？

逻辑错题必须写出压缩后的条件或论证结构，禁止只抄解析文字。

23. 一页考场速查版

总流程：认题型 → 提取规则 → 排除 → 全部验证

图推：
相似看位置/样式；凌乱看数量/属性；小点箭头看功能
规律必须解释全部图形，尝试一个入口无果再换一次，仍无果就走

定义：
主体 + 条件 + 方式 + 对象 + 目的/结果
违反一个必要条件即可排除；只认题干定义，不凭生活经验

类比：
先造句定一级关系，再比必然/或然、主要/次要、种属/组成等二级关系

翻译：
如果/只要 A，就 B：A→B
只有 A，才 B：B→A
A→B 等价于 非B→非A
肯后、否前均不能推出
非(A且B)=非A或非B；非(A或B)=非A且非B

真假：
所有A是B ↔ 矛盾：有的A不是B
所有A不是B ↔ 矛盾：有的A是B
先找矛盾对，再数真假

论证：
先写“论据→结论”
加强：搭桥、前提、排他因、补证据
削弱：断桥、他因、反向因果、反例、样本偏差
前提题用否定代入；解释题要同时解释冲突两端

分析推理：
列表、确定条件优先、最大信息、选项代入、二分假设

止损：
图推换一次观察角度仍无规律 → 走
逻辑 60—90 秒无有效链条 → 走
第二轮只回收已经有图、表、翻译或明确二选一依据的题

最后只记一句：

判断推理不是想到一个可能规律，而是找到一个能解释全部条件、排除其余选项的规律。
