图形推理：分类导航与遍历清单

用途：做题时先判断图形属于哪一类，再只遍历对应规律；不要从“平移”一路把所有考点试到“一笔画”。 使用方式：先看第 1 节总导航；专项学习看第 3—6 节；考前只看第 7 节。 来源说明：分类思路参考知乎答主“萧萧枝叶”的《行测的图推部分怎么提速和总结规律？》，本文件结合个人备考需求重新组织、改写并补充验证与止损规则，未转载原图或大段原文。

0. 先记住一句话

先看图形之间像不像、重复不重复，再决定查位置、样式还是数量属性。

图推有两套发动机：

  • 图感直达：出现强特征时，直接检查高概率规律；
  • 分类遍历：没有明显感觉时，按 A/B/C/D 分类，再在该类内部依次排查。

“图感”不是玄学，而是大量做题后形成的“特征 → 考点”条件反射；分类遍历则是图感尚未形成时的保底系统。

如果当前 Markdown 阅读器不渲染 Mermaid，就使用下面这一行文本版：

组成相同 → A 位置｜元素重复 → B 复现｜整体相似有增删 → C 样式｜完全不同 → D 属性/特殊/数量

分类时只问三个问题

  1. 每幅图的“零件”基本一样吗？一样但位置不同，就是 A 类。
  2. 零件不完全一样，但某些元素一直重复出现吗？是，就是 B 类。
  3. 整体轮廓或线条大体相似，只差增删、重合或运算吗？是，就是 C 类；都不是，进入 D 类。

分类不是目的，只是为了缩小搜索范围。若某题同时有两类特征，先查更直观、规则更简单、能覆盖全部图形的那一条。

2. 强特征：看到后先查什么

一眼看到的特征 第一反应 第二检查项
图形零件完全相同 平移、旋转、翻转 位置遍历
黑白宫格或分区涂色 黑白运算、平移 旋转、翻转
相同小元素反复出现 遍历、种类数 相邻图形共同元素
两图合成一图或一图拆成两图 加减、叠加 去同存异、去异存同
图形都很对称 对称轴数量、方向 轴与点线面的关系
圆、弧、直线混排 曲直性 直曲数量、交点
封闭区域很多 面数 内外面积、封闭性
交叉线很多 交点数 交点类型、内外交点
五角星、日字、田字及相连线图 一笔画、奇点 最少笔画数
明显凹陷或凸起 凹凸性 凹口数量、方向
每图都有小黑点、箭头或短线 功能元素的位置关系 标记的边、角、面属性
两个图形相交、相离、相压或内含 位置关系 交叠部分的点线面属性

强特征只负责提出假设，不负责证明答案。仍须用至少两组图验证，不能“看到五角星就无条件选一笔画”。

3. A 类：组成相同，只是位置不同

3.1 遍历顺序

平移 → 旋转 → 翻转 → 位置遍历

3.2 平移

必须说清四件事：

谁在移动 + 向哪里移动 + 每次几步 + 到边界后如何处理
  • 方向：上、下、左、右、顺时针、逆时针；
  • 步数：恒定、递增、递减、周期变化；
  • 路径：直线、环形、折返；
  • 边界：循环回到起点、反弹、改变方向；
  • 多个元素：可能同向、反向或轮流移动。

黑白宫格题先把每个黑块当作独立元素，比较相邻两图的对应位置；九宫格中间区域变化明显时可先查平移，不变时再查旋转。

3.3 旋转

  • 方向：顺时针或逆时针；
  • 角度：固定角度，或按一定数列增减；
  • 中心：整图绕中心转，还是局部元素各自转；
  • 内外元素：同向、反向或交替旋转。

3.4 翻转

  • 左右翻转：相当于照竖直镜子；
  • 上下翻转：相当于照水平镜子；
  • 判断旋转还是翻转：盯住不对称标志，如缺口、箭头、长短边或“手性”。

若旋转与翻转都能解释前一组，优先选规则更统一、步骤更少，并能解释所有图形者。

3.5 位置遍历

同一元素在一组图中把若干位置各走一次，不重复、不遗漏。九宫格常见：每行或每列的元素位置恰好齐全。

4. B 类：相同元素反复出现

4.1 遍历顺序

遍历 → 运算 → 种类数 → 拆分后平移 → 相邻复现

4.2 遍历

  • 数量遍历：同类元素在每幅图出现次数满足齐全、恒定或周期；
  • 位置遍历：某种元素在各位置各出现一次；
  • 九宫格优先检查每行、每列是否“种类齐全且不重复”。

4.3 运算

  • 黑白区域逐位置运算；
  • 每图都含相同种类、不同数量元素时，检查数量加减、差值、倍数或奇偶；
  • 运算顺序必须在所有对应位置一致，不能为了迁就选项临时换规则。

4.4 元素种类数

不要只数总个数，还要分开看：

  • 每图元素种类数是否恒定；
  • 某一元素的个数是否递增、递减或周期变化；
  • 不同元素之间是否存在数量和、差或替换关系。

4.5 拆分后平移

当图形像被分成左右、上下或内外两部分时，分别追踪各部分，不要把整图绑在一起观察。

4.6 相邻复现

相邻两图可能共享一个元素，或前图的某个元素传递到后图。检查：

图 1 与图 2 的共同元素
图 2 与图 3 的共同元素
共同元素是否按统一规则变化

5. C 类：整体相似，只有线条或局部不同

5.1 遍历顺序

相加/相减 → 去同存异 → 去异存同

这一类常见外观：

  • 图形大体相似，只增减了个别线条；
  • 含有明显相同轮廓；
  • 一个复杂图形可由两个简单图形组合；
  • 九宫格前两图运算得到第三图。

5.2 相加或相减

  • 相加：把前两图全部线条或区域合并；
  • 相减：从复杂图形中减去某些线条或元素；
  • 拆分：复杂图形能否分解成另外两个图形。

5.3 去同存异

两图共同部分消失，只保留不同部分。

5.4 去异存同

不同部分消失，只保留共同部分。

5.5 验证动作

不要用“整体看起来差不多”验证。任选两个明确位置，写出局部运算表，再检查剩余位置。若同样输入产生不同输出，当前规则立即作废。

6. D 类：不相同也不相似

D 类看起来最乱，但不代表要把所有数字都数一遍。顺序是：

先看整体属性 → 再看图形关系或功能元素 → 最后选择一个有依据的对象计数

6.1 属性规律

属性 具体检查
封闭性 开放、封闭、半封闭，或封闭部分数量
对称性 轴对称、中心对称、对称轴数量与方向
曲直性 全直、全曲、直曲混合，内外是否同曲直
面积关系 内外、左右或上下区域面积大小关系
包含性 是否都含某种多边形、圆、直角、星形等元素
凹凸性 凹或凸，凹口数量及方向

注意：“有或没有”还可能升级为“有几个”。例如每图都含封闭区域只是第一层，封闭区域数量可能才是真正规律。

6.2 特殊规律

图形连接

  • 公共边连接、点连接、线连接；
  • 有公共边：再看公共边属性、两侧面积或其他属性关系；
  • 无公共边：看连接点的有无、数量和位置。

位置关系

  • 相交：检查交叠部分的形状、边、角、面；
  • 相离：检查对应方向上的边或图形属性；
  • 相压：检查上下图形的对应属性；
  • 内外：检查内外图形的曲直、开闭、对称或数量关系。

功能元素

小黑点、箭头、短线、阴影块不一定用于计数，更可能在标记：

  • 内部、外部或边界；
  • 长边、短边、直边或曲边；
  • 锐角、直角、钝角；
  • 最大面、最小面；
  • 相邻面或相对面；
  • 某元素的移动路径。

6.3 数量规律

计数对象 细分方向
点 线线交点、直曲交点、切点、端点、奇点、内外交点
线 直线数、曲线数、线段数、直曲和差或比例
笔画 一笔画、最少笔画数、奇点数、连通部分数
对称轴 数量、方向、是否与其他元素重合或垂直
角 锐角、直角、钝角，小于 180° 的内角
面 总面数、直线面、曲线面、内外面
元素 种类数、个数、部分数、相同元素的位置

数量序列常见关系：恒定、等差、递增递减、奇偶交替、周期、分组，以及九宫格行列间的加减。

一笔画最低限度

  • 连通图有 0 或 2 个奇点：可以一笔画；
  • 连通图有 2n 个奇点且大于 2：最少通常需要 n 笔；
  • 图形不连通：各连通部分分别判断后相加。

先确认连通，再数奇点；不能只看到星形或日字形就直接下结论。

7. 考场一页版

7.1 十秒分类

A 组成相同：平移 → 旋转 → 翻转 → 位置遍历
B 元素重复：遍历 → 运算 → 种类 → 拆分平移 → 相邻复现
C 整体相似：加减 → 去同存异 → 去异存同
D 完全不同：属性 → 特殊关系 → 有依据地计数

7.2 强特征直达

多面 → 面数
多交叉 → 交点
星、日、田、相连线图 → 笔画/奇点
小黑点、箭头 → 功能位置
明显对称 → 对称轴
明显凹口 → 凹凸
两图合一图 → 样式运算

7.3 验证标准

一个合格规律必须同时满足：

  1. 能解释至少两组图，而不是只解释一处；
  2. 对全部关键元素有效；
  3. 不需要频繁增加例外；
  4. 能得到唯一选项。

7.4 止损标准

  • 约 10 秒仍未完成分类：先看强特征；
  • 一个方向验证失败：立即换同类中的下一规则，不修补旧假设；
  • 约 50—60 秒仍没有稳定路径：标记并跳过；
  • 第二轮只回收“已有明确思路、差一步”的题，不重新从头穷举。

时间不是绝对值，要按个人限时数据调整；关键是避免在一道陌生图推上持续沉没成本。

8. 专项训练：把导航图练成图感

每次训练建议做同来源真题 10—15 题。每题完成后只补一条记录：

题号 A/B/C/D 具体规律 应看到的触发特征 首次用时 是否误判入口
例 D 交点数等差 多条线反复交叉 72 秒 是，先数了面

错题复盘只回答四个问题：

  1. 我应该把它分到哪一类？
  2. 题面最明显的触发特征是什么？
  3. 我是没学会规律，还是入口选错？
  4. 下次看到什么特征，要立刻想到什么？

不要把解析整段抄进错题本。真正有用的是一条个人触发语，例如：

看到很多交叉线，先数交点类型，不先数总线条。
看到相同零件只换位置，先查位置，不碰数量。

每累计 30—50 道真题，再按自己的错题数据调整分支优先级。导航图是起点，最终版本必须由你的正确率和耗时共同决定。
