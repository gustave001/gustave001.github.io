行测数量关系：方法、公式与考场白名单

适用：江西省考数量关系，从零建立题型识别和取舍系统。
核心目标：不是做完全部数量题，而是快速找出最值得拿的题。
个人策略：奥数经历只作为潜在优势；用至少 20 道限时真题验证，不凭经历决定投入。

配套专题：数量关系题型导航与考场选择。本文件用于公式和考场白名单速查，专题库用于按题型学习“如何识别、怎样建模、何时止损”。

0. 数量关系的真正任务

考场上数量关系通常同时考三件事：

  1. 能否识别题型；
  2. 能否选择最短方法；
  3. 能否在低收益题上及时停止。

数量题不是必须使用“标准公式”。同一道题可能用方程、比例、特值、代入、枚举或整除解决。优先级是：

能口算不列式，能代入不硬解，能设特值不设复杂未知数，能排除不精算。

但所有捷径都必须满足题意，不能为了速算擅自改变整数、正数、不同对象等条件。

1. 考场共用的五步法

  1. 扫题识别：用 5—10 秒判断题型和数据友好程度；
  2. 抓等量关系：题目中什么总量相等、前后不变或受到约束？
  3. 选方法：代入、特值、比例、方程、枚举还是公式；
  4. 先看选项：利用整除、奇偶、尾数、范围和数量级排除；
  5. 检查边界：整数、至少/至多、是否包含端点、是否重复计数。

A/B/C 扫题标记

  • A：题型熟悉，能立即列式或代入，第一轮做；
  • B：方法知道但计算较长，第二轮回收；
  • C：无清晰路径、条件复杂或高风险，直接放后。

扫题时不是判断“会不会做”，而是判断“单位时间值不值得做”。

2. 六种通用解题工具

2.1 选项代入

适合：

  • 问具体数值且选项数量少；
  • 条件关系顺算容易、逆推复杂；
  • 年龄、利润、行程、工程等可快速验证；
  • 问最大/最小且选项有序。

技巧：

  • 选项有序时先代中间值，根据结果偏大偏小继续二分；
  • 先检查整除、奇偶和范围，减少代入次数；
  • 代入必须验证全部条件。

2.2 设特值

适合只给比例、效率、浓度、增长率，没有绝对量的题。

常用特值：

  • 比例 a:b → 分别设为 a、b 或其公倍数；
  • 工作效率比 2:3 → 设效率为 2、3；
  • 百分数较多 → 总量设 100；
  • 分数分母多 → 设为分母最小公倍数。

前提：所求结果不依赖绝对规模，或题目允许按比例缩放。

2.3 方程法

适合存在明确等量关系的题。

基本步骤：

找不变量或总量
→ 设最少的未知数
→ 用题干原顺序列式
→ 结合选项与整数条件简化

优先设题目直接所求或最容易表达其他量的对象。

2.4 比例法

适合总量与分量、速度时间、效率时间、价格销量等乘积关系。

若乘积一定：

A × B = 常数
则 A 与 B 成反比

例如工作量一定时：

效率比 = 时间的反比

2.5 枚举法

适合：

  • 对象数量少；
  • 整数解有限；
  • 排列、日期、比赛、钱币组合；
  • 约束条件多但范围小。

枚举必须有顺序，例如按某变量从小到大列，避免重复或遗漏。

2.6 极端与边界

适合至少、至多、最多、最少、保证等问法。

核心思路：

为了让目标尽可能晚发生，最坏情况能怎样安排？

“至少保证”常用：

最坏情况 + 1

3. 数字特性：先排除再计算

3.1 奇偶性

  • 奇 ± 奇 = 偶；
  • 偶 ± 偶 = 偶；
  • 奇 ± 偶 = 奇；
  • 奇 × 奇 = 奇；
  • 乘积有一个偶数即为偶数。

3.2 常用整除规则

除数 判断规则
2 末位是偶数
3 各位数字和能被 3 整除
4 末两位能被 4 整除
5 末位是 0 或 5
6 同时能被 2 和 3 整除
8 末三位能被 8 整除
9 各位数字和能被 9 整除
10 末位是 0
11 奇数位数字和与偶数位数字和之差能被 11 整除
25 末两位是 00、25、50、75

3.3 倍数与余数

若：

a 除以 m 余 r

可写成：

a = km + r

余数必须满足：

0 ≤ r < m

同余的常用运算：若 a≡r₁ (mod m)，b≡r₂ (mod m)，则：

a+b ≡ r₁+r₂
a-b ≡ r₁-r₂
ab  ≡ r₁r₂

最后再将余数化到 0 至 m-1。

3.4 尾数

乘方尾数通常按周期循环。例如：

  • 2^n 尾数：2、4、8、6，周期 4；
  • 3^n 尾数：3、9、7、1，周期 4；
  • 7^n 尾数：7、9、3、1，周期 4；
  • 8^n 尾数：8、4、2、6，周期 4。

指数除以周期看余数；余数为 0 时取周期最后一项。

3.5 最大公约数与最小公倍数

若两个正整数为 a、b：

最大公约数 × 最小公倍数 = a × b
  • 周期同时发生 → 常求最小公倍数；
  • 平均分组且每组尽量大 → 常求最大公约数。

4. 方程、比例与不定方程

4.1 和差关系

若：

x + y = S
x - y = D

则：

x = (S + D)/2
y = (S - D)/2

4.2 比例分配

若 A:B = m:n，总量为 S：

A = S × m/(m+n)
B = S × n/(m+n)

4.3 不定方程

例如：

ax + by = c

且 x、y 为非负整数。优先使用：

  • 整除；
  • 奇偶；
  • 尾数；
  • 范围；
  • 选项代入。

不必求出所有整数解，只需求符合题目边界的解。

4.4 鸡兔同笼模型

总头数 N，若全按较少腿数 a 计算，实际总腿数为 L，另一类腿数为 b：

较多腿动物数 = (L - aN)/(b-a)

本质是“先假设全是一类，再看差额”。可推广到价格、分值、载重等两档问题。

5. 工程问题

5.1 核心公式

工作总量 = 工作效率 × 工作时间

若总量一定：

效率与时间成反比

5.2 设总量

若甲单独 a 天完成，乙单独 b 天完成，可设总量为 a、b 的最小公倍数。

例如甲 6 天、乙 4 天完成，设总量 12：

甲效率 = 2/天
乙效率 = 3/天
合作效率 = 5/天
合作时间 = 12/5 天

5.3 合作与轮流

  • 同时工作：效率相加；
  • 一方产生、一方消耗：效率相减；
  • 轮流工作：先算一个完整周期完成量，再处理剩余；
  • 中途加入或退出：按时间段分别计算工作量。

5.4 效率变化

效率提高 r：

新效率 = 原效率 × (1+r)

总量不变时：

新时间 = 原时间 ÷ (1+r)

时间缩短比例不是简单等于效率提高比例。

5.5 水池进排水

进水为正效率，排水为负效率：

净效率 = 进水效率之和 - 排水效率之和

若净效率小于等于 0，则无法注满。

6. 行程问题

6.1 核心公式

路程 S = 速度 v × 时间 t

6.2 相遇

相向而行：

相遇路程 = (v₁ + v₂) × t

6.3 追及

同向追及：

追及距离 = (快速度 - 慢速度) × t

6.4 往返平均速度

等距离往返，去程速度 v₁、返程速度 v₂：

平均速度 = 2v₁v₂/(v₁+v₂)

不是 (v₁+v₂)/2。

若两段时间相等，平均速度才是速度的算术平均数。

6.5 流水行船

顺水速度 = 船速 + 水速
逆水速度 = 船速 - 水速
船速 = (顺水速度 + 逆水速度)/2
水速 = (顺水速度 - 逆水速度)/2

6.6 火车过桥/过人

  • 过一个点或人：路程为车长；
  • 完全通过桥：路程为车长 + 桥长；
  • 两列车完全错开：路程为两车长度之和；
  • 相向用速度和，同向用速度差。

6.7 环形跑道

  • 相向首次相遇：路程和为一圈；
  • 同向首次追上：路程差为一圈；
  • 多次相遇按相对运动累计圈数。

6.8 分段与提前/迟到

同一路程使用两种速度，利用时间差建立：

S/v慢 - S/v快 = 时间差

若题干说按某速度迟到、另一速度早到，两个时间差相加通常得到两方案总用时之差。

7. 经济利润问题

7.1 核心关系

利润 = 售价 - 成本
利润率 = 利润/成本
售价 = 成本 × (1 + 利润率)

亏损率同样以成本为分母：

售价 = 成本 × (1 - 亏损率)

7.2 折扣

折后价 = 原价 × 折扣

八折即原价的 80%，不是便宜 80%。

7.3 两次涨跌

先变动 r₁，再变动 r₂：

最终系数 = (1+r₁)(1+r₂)

先涨 20% 再降 20%：1.2×0.8=0.96，最终下降 4%。

7.4 总利润

总利润 = 单件利润 × 销量

价格变化影响销量时，不能只看单件利润，应比较乘积。

7.5 定价、折扣与利润率

若成本为 C，按成本加价 a 定价，再打折 d：

售价 = C(1+a)d
最终利润率 = (1+a)d - 1

8. 浓度与混合

8.1 核心公式

溶质质量 = 溶液质量 × 浓度
浓度 = 溶质质量/溶液质量

8.2 混合

混合后浓度
= 各溶液溶质质量之和 / 各溶液总质量

混合浓度一定在各原浓度最小值和最大值之间。

8.3 十字交叉

高浓度 c高、低浓度 c低 混成 c混：

高浓度溶液量 : 低浓度溶液量
= (c混-c低) : (c高-c混)

谁离混合浓度更远，所需量通常更少。

8.4 加水或蒸发

  • 加水：溶质不变，总量增加；
  • 蒸发水：溶质不变，总量减少；
  • 加溶质：溶质和总量都增加；
  • 倒出均匀溶液：溶质和溶液按同一比例减少，浓度不变。

8.5 重复倒出再补水

每次倒出总量的比例为 p，补回清水，重复 n 次：

剩余溶质 = 原溶质 × (1-p)^n

只在每次混合均匀、倒出比例相同且补至原总量时适用。

9. 容斥原理

9.1 两集合

|A∪B| = |A| + |B| - |A∩B|

若总人数为 N，两者都不属于的人数：

都不属于 = N - |A∪B|

9.2 三集合

|A∪B∪C|
= |A|+|B|+|C|
- |A∩B|-|A∩C|-|B∩C|
+ |A∩B∩C|

注意题目中的“两项都参加”是否包含三项都参加者，必须按题干口径处理。

9.3 至少重合数

两集合在总数 N 中至少重合：

至少重合 = |A| + |B| - N

结果小于 0 时下限取 0。

10. 排列组合

10.1 加法与乘法原理

  • 分类完成：各类方法数相加；
  • 分步完成：各步方法数相乘。

先问：这些方案是“任选一种路径”还是“必须依次完成多个步骤”？

10.2 排列与组合

从 n 个不同元素中选 m 个：

排列 A(n,m) = n!/(n-m)!      （顺序重要）
组合 C(n,m) = n!/[m!(n-m)!]  （顺序不重要）

并且：

C(n,m) = C(n,n-m)

10.3 相邻：捆绑法

要求若干元素相邻，把它们视为一个整体排列，再乘整体内部排列数。

例如 A、B 必须相邻，和另外 3 人排队：

把 AB 看作一组，共 4 个单位：4!
AB 内部：2!
总数：4!×2!

10.4 不相邻：插空法

先排列不受限制的元素，再把需分开的元素插入空隙。

例如 3 个相同红球不相邻地放入 4 个不同对象形成的 5 个空位，可从空位中选 3 个。

10.5 至少/至多：正难则反

至少一个 = 总数 - 一个都没有

求“至少”时，若反面情况简单，优先用补集。

10.6 环形排列

n 个不同元素围成一圈，若只把旋转视为相同：

(n-1)!

若正反方向也视为相同，还要结合题意除以 2。普通圆桌座位通常只消除旋转，不自动消除镜像。

10.7 分组与分配

  • 分到有名称的组：组之间可区分；
  • 分成无名称且同规模的组：需除以组之间交换产生的重复；
  • 先分组再分配时，警惕重复计数。

10.8 错位排列（了解）

每个元素都不在原位置，常见小规模：

D1=0，D2=1，D3=2，D4=9，D5=44

零基础阶段优先掌握小规模枚举，不必先背通项。

11. 概率

11.1 等可能事件

概率 = 满足条件的情况数 / 所有等可能情况数

先确认所有基本结果是否真的等可能。

11.2 至少一次

至少一次 = 1 - 一次都没有

若每次独立，单次成功概率为 p，进行 n 次：

至少成功一次 = 1 - (1-p)^n

11.3 独立事件

P(A且B) = P(A)P(B)

仅在 A、B 独立时适用。

11.4 互斥事件

若 A、B 不能同时发生：

P(A或B) = P(A) + P(B)

一般情况：

P(A或B)=P(A)+P(B)-P(A且B)

11.5 有放回与无放回

  • 有放回：每次总体组成不变，常可视为独立；
  • 无放回：后一次概率随前一次结果变化。

无放回题也可使用组合计数，往往比逐步概率更简洁。

11.6 条件概率（了解）

P(A|B) = P(A且B)/P(B)

表示在 B 已发生的条件下 A 的概率。

12. 几何问题

12.1 平面图形

图形 周长/面积
长方形 C=2(a+b)，S=ab
正方形 C=4a，S=a²
三角形 S=底×高/2
平行四边形 S=底×高
梯形 S=(上底+下底)×高/2
圆 C=2πr，S=πr²
扇形 弧长 = n/360×2πr；面积 = n/360×πr²

12.2 立体图形

图形 体积
长方体 V=abc
正方体 V=a³
柱体 V=底面积×高
锥体 V=底面积×高/3
球 V=4πr³/3

12.3 相似图形

边长比为 k：

周长比 = k
面积比 = k²
体积比 = k³

12.4 勾股数

常见：

3-4-5
5-12-13
6-8-10
8-15-17
7-24-25

12.5 几何最值

在周长一定的常见规则图形中，越接近“均匀”，面积通常越大；矩形周长一定时，正方形面积最大。

实际题目先看是否可用割补、平移、比例或选项代入，避免一开始建立复杂坐标。

13. 年龄问题

13.1 核心不变量

两人年龄差永远不变

每过 n 年，每个人都增加 n 岁；k 个人年龄和增加 kn。

13.2 倍数关系

设当前年龄后按题目时间变化列方程。年龄倍数会随时间变化，年龄差不变。

13.3 代入选项

若问某人当前年龄，且选项均为合理整数，代入常比解方程更快。

检查年龄必须非负，出生前的“年龄”通常不成立，除非题目有特殊设定。

14. 日期、星期与周期

14.1 星期推进

经过 n 天，星期移动：

n mod 7

“过 n 天”与“第 n 天”是否包含当天，要按语义判断。

14.2 平年与闰年

  • 非整百年份：能被 4 整除的是闰年；
  • 整百年份：必须能被 400 整除才是闰年；
  • 平年 365 天，闰年 366 天。

14.3 月份天数

大月 31 天：1、3、5、7、8、10、12 月
小月 30 天：4、6、9、11 月
2 月：平年 28，闰年 29

14.4 周期问题

多个事件再次同时发生，通常求周期的最小公倍数。

有起点偏移时，不能只求最小公倍数，还要写成同余条件或逐步验证。

15. 钟表问题

15.1 角速度

分针：6°/分钟
时针：0.5°/分钟
相对速度：5.5°/分钟

15.2 某时刻夹角

h 时 m 分：

时针角度 = 30h + 0.5m
分针角度 = 6m
夹角差 = |30h - 5.5m|

若差大于 180°，小夹角为 360° - 差。

15.3 重合、垂直、相反

根据相对角度分别为 0°、90°、180° 建立方程，并注意一小时内是否存在多个解。

16. 植树、方阵与排队

16.1 直线植树

  • 两端都植：棵数 = 间隔数 + 1；
  • 一端植一端不植：棵数 = 间隔数；
  • 两端都不植：棵数 = 间隔数 - 1。

16.2 环形植树

棵数 = 间隔数

16.3 方阵

每边 n 人的实心方阵：

总人数 = n²
最外层人数 = 4n - 4

从外向内每减少一层，每边通常减少 2 人。

16.4 排队位置

某人从前数第 a，从后数第 b：

总人数 = a + b - 1

两人之间人数要根据两人的位置差再减 1。

17. 比赛、计分与统筹

17.1 比赛场次

  • 单循环：每两队比赛一次，C(n,2)=n(n-1)/2；
  • 双循环：n(n-1)；
  • 单淘汰决出冠军：比赛 n-1 场。

17.2 计分

先用：

总积分 = 各类比赛场数 × 对应积分之和

若胜负双方总积分与平局双方总积分不同，可以用总场次和总积分反推平局场次。

17.3 统筹安排

核心是识别哪些工作可以并行，哪些必须串行。

  • 串行时间相加；
  • 并行任务看最长路径；
  • 有先后依赖时画简单流程线；
  • 人或设备有容量限制时不能重复占用。

18. 极值、抽屉与最不利构造

18.1 抽屉原理

把 n 个对象放进 m 个抽屉，至少有一个抽屉不少于：

向上取整(n/m)

18.2 保证至少一个同类

若有 m 类，为保证至少出现两个同类：

最坏情况每类取 1 个，再取 1 个
= m + 1

若每类数量有限或要求更多同类，要按最坏情况重新构造。

18.3 保证取到目标

先尽可能取非目标、或让目标条件不成立，然后再加 1。

例如袋中有红、蓝、白三色球，保证至少取到一种颜色 2 个，最坏先各取 1 个，共 3 个，再取 1 个，因此为 4 个。

18.4 和一定时的乘积

两个正数和一定，越接近，乘积越大；差越大，乘积越小。整数题还需满足取整和边界。

19. 数字推理

如果试卷出现数列题，按“先看变化最简单的关系”处理，不做无穷试探。

19.1 默认观察顺序

直接相邻关系
→ 作差
→ 作商
→ 差或商再作变化
→ 分组/交叉
→ 递推
→ 幂次与特殊数列

19.2 高频规律

  • 等差：相邻差相同；
  • 二级等差：相邻差构成等差数列；
  • 等比：相邻比值相同；
  • 和数列：后项由前两项之和或加减常数得到；
  • 积数列：后项由前两项乘积再加减常数得到；
  • 分组/交叉：奇数项和偶数项分别成规律；
  • 幂次：平方、立方或 a^n±常数；
  • 质数：2、3、5、7、11、13……；
  • 周期数列：若干项后重复。

19.3 分数数列

先观察：

  • 分子、分母分别成规律；
  • 通分或约分后是否更清晰；
  • 分子分母之间是否存在和、差、积关系；
  • 整体是否可拆成整数加分数。

19.4 止损

一个基础入口无法解释全部项，再换一次观察方式；仍无稳定规律则跳过。能拟合前几项但不能唯一确定下一项的“复杂规律”不采用。

20. 牛吃草与动态增减模型

适用特征：原有存量存在，同时每天还在增加或减少；若干消费者共同消耗。

设：

  • 原有草量为 Y；
  • 每天新增长的草量相当于 x 头牛一天的食量；
  • n 头牛吃 t 天。

则：

Y = (n - x)t

两种情况可列：

(n₁-x)t₁ = (n₂-x)t₂

先求每天新增量对应的 x，再求原始存量 Y 或其他情形。

可推广到：

  • 水库原有水量 + 每天流入 - 每天排出；
  • 库存原有货物 + 每天生产 - 每天销售；
  • 排队原有人数 + 每分钟新增 - 每分钟办理。

如果存量每天减少而不是增加，要按题意调整净变化方向，不能机械套正号。

21. 高频题干信号 → 优先方法

题干信号 优先想到
“单独完成、合作、中途加入” 工程：总量=效率×时间
“相向、同向追上、提前/迟到” 相遇/追及、路程差
“往返且路程相同” 调和平均速度
“成本、售价、打折、利润率” 利润率分母是成本
“混合、浓度、加水、蒸发” 溶质不变量、十字交叉
“至少一个” 补集：总数减一个都没有
“相邻” 捆绑法
“不相邻” 插空法
“保证、至少取多少” 最坏情况 + 1
“若干天后再次同时” 最小公倍数/周期
“原有存量且每天新增、多人消耗” 牛吃草：原量=净消耗×时间
“一串数求下一项” 差、商、交叉、递推、幂次
“总数、总腿数/总价” 鸡兔同笼、方程、假设法
“比例多、无绝对量” 设特值
“问具体值且有四个选项” 先查整除，再代入
“整数个、至少/至多” 不定方程、枚举、边界
“人均、每个、单位面积” 平均数/乘积关系
“每边若干、最外层” 方阵公式
“从前第几、从后第几” 前+后-1

22. 哪些题优先进入白名单

以下是零基础的候选白名单，不是最终结论：

第一优先候选

  • 基础工程合作；
  • 基础相遇追及；
  • 利润、折扣；
  • 比例分配；
  • 年龄与和差；
  • 植树、排队、方阵；
  • 星期周期；
  • 基础容斥；
  • 选项可直接代入的题；
  • 可用整除、奇偶、尾数快速排除的题。

第二优先候选

  • 浓度混合；
  • 分段行程；
  • 基础排列组合与概率；
  • 基础几何；
  • 有限整数枚举；
  • 简单比赛计分和统筹。

高风险候选

  • 条件繁复的排列组合；
  • 多阶段概率；
  • 复杂几何构造；
  • 长不定方程；
  • 多人多次相遇；
  • 需要大量分类讨论且选项不能帮助排除的题。

白名单必须由你的数据决定。某题型只有在不少于两组训练中保持较高正确率和合理用时，才正式进入白名单。

23. 数量关系的主力资格

至少完成 20 道覆盖多类题型的限时真题后再判断。

数量可以升级为主力模块，需要同时满足：

  1. 能在扫题后识别可做题；
  2. 白名单题正确率达到约 75% 或以上；
  3. 白名单题多数能在约 60—90 秒形成有效路径；
  4. 连续两组表现接近；
  5. 给数量增加时间，不会挤掉资料、判断和言语的稳定得分。

否则数量保持“扫题 + 选择性拿分”，放在考场靠后位置。

三色清单

分类 标准 考场动作
白名单 一眼识别、方法稳定、正确率高 第一轮优先做
观察名单 方法知道但速度慢或波动大 第二轮有时间回收
暂放名单 无稳定路径或投入产出低 不恋战，策略性作答

24. 考场时间与止损

总计划给数量关系的初始时间盒是 12 分钟。不是每题平均分配，而是：

先用约 1—2 分钟扫题
→ 完成白名单题
→ 回收观察名单中已有路径的题
→ 到点停止

单题止损

  • 读完 20—30 秒仍无法识别题型：先走；
  • 约 60 秒仍没有列式、代入或枚举路径：走；
  • 建立方法但计算超过预期：看选项能否排除，否则标记；
  • 分类讨论分支快速增加：转代入或放弃；
  • 做完后结果不在选项：只检查一次单位、边界和计算，不从头无限重算。

第二轮只回收

  • 已列出方程，只差短计算；
  • 已排除两项，可用整除或代入验证；
  • 已完成枚举框架；
  • 白名单题因一处计算中断。

不要回收从题型识别就失败的题。

25. 训练方法

第一轮：题型识别

每类先做基础题，不限时但必须写：

题干信号是什么？
核心不变量是什么？
我为什么选择这个方法？
是否存在更短方法？

第二轮：同题多解比较

只对典型题比较方程、比例、特值、代入等方法。目的不是炫技，而是找考场最短路径。

第三轮：混合扫题

拿 10—15 道不同题型，只做以下动作：

  1. 限时扫题；
  2. 标 A/B/C；
  3. 先做 A；
  4. 统计 A 类识别准确率。

如果把实际难题误判为 A，说明题型判断或难度判断仍需调整。

第四轮：白名单限时

每个候选白名单题型至少做两组，记录正确率、形成路径时间、完成时间和错因。

数量训练的关键指标不是“总共做了几题”，而是：

扫题后选出来的题，有多少真的在时间内做对？

28. 一页考场速查版

总流程：扫题标 A/B/C → 找不变量 → 选最短方法 → 用选项排除 → 查边界

通用工具：
有选项先想代入；只有比例先想特值；等量明确列方程
整数题先查整除/奇偶/尾数；范围小就有序枚举
至少保证 = 最坏情况 + 1

工程：总量=效率×时间；合作效率相加；总量设完成天数公倍数
行程：S=vt；相遇用速度和，追及用速度差
等距离平均速度=2v1v2/(v1+v2)
利润：利润率=利润/成本；售价=成本×(1+利润率)
浓度：溶质=溶液×浓度；加水/蒸发时抓溶质不变
容斥：A∪B=A+B-A∩B
排列组合：顺序重要用排列；不重要用组合；相邻捆绑，不相邻插空
概率：有利情况/总情况；至少一次=1-一次都没有
几何：边长比 k → 周长 k、面积 k²、体积 k³
年龄：年龄差不变
周期：共同再发生常求最小公倍数
排队：前第a、后第b，总人数=a+b-1

止损：
20—30 秒认不出题型 → 先走
约 60 秒没有有效列式/代入/枚举路径 → 走
第二轮只回收已经形成路径的题

白名单资格：至少 20 题样本；正确率约 75%+；连续两组稳定；不挤占稳定模块

最后只记一句：

数量关系不是比谁会的题型多，而是比谁能最快认出值得做的题，并及时放弃不值得做的题。
