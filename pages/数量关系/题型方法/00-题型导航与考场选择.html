行测数量关系：题型导航与考场选择

数量关系不是先背公式，而是先识别模型。
每道题先完成三件事：辨题型、找不变量、选最短方法。

1. 题型地图

题型卡 题干信号 第一反应 考场属性
方程、比例与鸡兔同笼 总数、差额、比例、两档价格/分值 设最少未知数；先假设全是一类 高频基础，优先
工程与牛吃草 单独完成、合作、效率、边做边增加 总量设公倍数；净效率 高频基础，优先
行程问题 相遇、追及、往返、流水、过桥 S=vt；画方向和时间线 高频，选简单结构
经济利润 成本、定价、折扣、利润率、销量 成本设 100；比较总利润 高频基础，优先
浓度与混合 加水、蒸发、混合、倒出补回 守住溶质；十字交叉 模型固定，优先
容斥原理 至少一种、都不、两项/三项都参加 画集合；加和减重 两集合优先，三集合看口径
排列组合与概率 安排、选取、至少一次、相邻/不相邻 先判顺序；至少用补集 波动较大，挑简单题
几何问题 面积、体积、相似、路径、阴影 比例、割补、特殊图形 图形清楚则做，复杂则放

2. 题型识别树

题目在描述“做完一项工作”吗？
├─ 是 → 工程；若工作量还持续增加 → 牛吃草
└─ 否
   ├─ 描述移动、相遇、追上、过桥 → 行程
   ├─ 描述价格、折扣、成本、利润 → 经济利润
   ├─ 描述溶液、浓度、加水、蒸发 → 浓度混合
   ├─ 描述参加多类活动、至少一类 → 容斥
   ├─ 描述选人、排座、安排、概率 → 排列组合与概率
   ├─ 描述长度、面积、体积 → 几何
   ├─ 描述保证、至少取多少 → 最不利构造
   └─ 其余先尝试方程、比例、鸡兔同笼或数字特性

题型不是互斥的。一道利润题也可能最终用鸡兔同笼，一道工程题也可能用比例。题型负责找到关系，通用方法负责完成计算。

3. 通用方法选择顺序

第一步：看选项能否反推

适合代入：

  • 问一个具体整数；
  • 选项有序；
  • 从答案往题干验证很容易；
  • 正推要设多个未知数。

有序选项先代中间项，再按偏大偏小缩小范围。

第二步：看能否设特值

只有比例、效率、利润率、浓度而没有绝对量时，常设：

百分数 → 总量或成本设100
若干分数 → 总量设分母最小公倍数
效率比 → 效率直接设成对应份数

第三步：利用整数条件

数量关系中的人数、件数、车辆数通常为整数。先看：

  • 奇偶；
  • 整除；
  • 尾数；
  • 上下界；
  • 余数。

它们经常能把四个选项缩成一个或两个。

第四步：再列方程

方程只设最少未知数。优先设题目所求，或能最方便表达其他量的对象。

4. A/B/C 考场白名单

A 类：看到模型就有路径

  • 简单工程、相遇追及；
  • 折扣利润、浓度加水；
  • 两集合容斥；
  • 年龄差、星期周期；
  • 植树、排队位置、比赛场次；
  • 鸡兔同笼与简单不定方程；
  • 至少保证类的最坏情况加一。

标准：10 秒内能写出主关系，通常 60—90 秒内可完成。

B 类：方法明确但步骤较长

  • 分段行程；
  • 轮流工程；
  • 三集合容斥；
  • 普通排列组合与概率；
  • 简单几何拼接；
  • 两三个条件的不定方程。

第二轮回收。

C 类：高风险

  • 条件很多、需要大量分类讨论；
  • 陌生几何辅助线；
  • 复杂排列分组去重；
  • 看不出唯一规律的数字数列；
  • 建模后有三个以上未知数且没有整数约束；
  • 阅读两遍仍无法说出“不变量是什么”。

直接放后，不让一道题拖垮整套卷。

5. 单题止损线

开始计算前，应能用一句话说清：

这道题的核心等量关系是 ______。

出现以下任一情况，考虑立即跳过：

  • 20 秒仍未识别题型；
  • 写出三个未知数却只有一两个有效方程；
  • 需要枚举但没有确定枚举顺序和范围；
  • 计算到一半发现单位或对象反复切换；
  • 两分钟仍未接近任何选项。

6. 推荐训练顺序

第一层：方程比例 → 工程 → 利润 → 浓度
第二层：行程 → 容斥 → 年龄日期 → 植树比赛
第三层：极值抽屉 → 排列概率 → 几何
穿插训练：数字特性与选项代入

每类题练习时记录：

识别词：我凭什么认出题型？
不变量：题目前后什么不变？
最短法：方程、比例、特值、代入还是枚举？
止损点：什么特征出现时我不该继续？

7. 总口诀

工程设总量，行程画方向；
利润设成本，浓度守溶质；
容斥去重复，排列先判序；
年龄差不变，周期只看余；
植树分点段，比赛防重计；
至少保底题，最坏再加一；
未知量太多，先代选项和整除。
