行测言语理解：方法与考场速查卡

适用：江西省考行测言语理解与表达，从零建立方法。
目标：不是培养“文学鉴赏”，而是在有限时间内找到文段证据，排除越界选项。
使用方法：正文用于学习和查错；考场主要执行第 1、15、16、18 节。

0. 先建立一个正确认识

言语理解不是纯粹依靠语感。稳定作答依赖四件事：

  1. 题型：题目到底问主旨、意图、细节、排序，还是填词？
  2. 结构：文段中哪些句子是背景、问题、观点、解释、例子或对策？
  3. 主题：文段始终围绕谁、讨论它的什么方面？
  4. 边界：选项有没有偷换主体、扩大范围、加重语气或强加因果？

最重要的原则是：

答案不是“听起来最正确”的一句话，而是“最准确概括这段材料”的一句话。

言语题常用社会治理、科技、人文、生态等话题包装，但一般不要求你具备专业知识。材料证据优先于个人经验。

1. 所有言语题共用的四步法

第一步：识别题型

先看题目问法，确认任务：

  • “主旨、中心、旨在说明” → 主旨概括；
  • “意在强调、意在说明” → 意图判断；
  • “理解正确/不正确的是” → 细节判断；
  • “可以推出/可知” → 推断判断；
  • “最适合做标题” → 标题选择；
  • 横线填句子 → 语句填空；
  • 句子重新排列 → 语句排序；
  • “接下来最可能讲” → 下文推断；
  • 横线填词语/成语 → 逻辑填空。

题型认错，后面读得再仔细也可能答偏。

第二步：找主题

用一句最简单的话回答：

这段话一直在谈谁？主要谈它的什么问题、特点、原因、作用或对策？

主题通常由两部分组成：

核心主体 + 论述重点

例如：

核心主体：传统村落保护
论述重点：应在活态传承中避免过度商业化

只出现一次的例子、名人、地区或技术名词，不一定是核心主体。

第三步：划分结构

不要逐字平均用力。判断每句话承担什么功能：

功能 常见表现 阅读动作
背景 随着、近年来、在……背景下 知道话题即可
现象 当前出现某种情况 看后面如何评价
问题 但、然而、令人担忧的是 留意后续原因或对策
原因 因为、由于、究其原因 判断题目是否问原因
观点 可见、实际上、应当、需要 高度关注
对策 必须、关键在于、要、应 常是作者落脚点
解释 也就是说、换言之、这意味着 帮助理解前文
例子 例如、以……为例 用来证明观点，不喧宾夺主
数据 调查显示、数据显示 看它支撑哪个结论
结论 因此、所以、由此可见 一般高度关注

第四步：用证据审查选项

对每个候选选项检查：

  1. 主体和材料一致吗？
  2. 讨论重点一致吗？
  3. 范围有没有扩大或缩小？
  4. 语气有没有从“可能”变成“必然”？
  5. 因果、条件、时间有没有被改变？
  6. 它是全文重点，还是只概括了一个例子？

找不到材料依据的选项，即使观点正确，也不选。

2. 关联词怎么用：提示结构，不是机械口诀

2.1 转折

常见词：

但、但是、然而、却、其实、实际上、殊不知

一般作用：前文作铺垫、让步或常规认识，后文提出修正或重点。

示意：

某技术应用广泛，但其数据安全风险仍需警惕。

重点大概率是“需要警惕数据安全风险”。

注意：不能机械地“见但选但后”。如果转折后只是补充细节，或者全文还有进一步结论，应看完整结构。

2.2 因果

常见词：

因为、由于、因此、所以、导致、使得、缘于、源于
  • 因为 A，所以 B：若题目问主旨，通常更关注作者想说明的结果 B；
  • 若题目问原因，则重点是 A；
  • 选项不能颠倒因果，也不能把相关关系改成因果关系。

2.3 递进

常见词：

不仅……而且……
不但……还……
更、尤其、甚至、重要的是

递进后往往更重要，但完整概括有时需要同时包含前后两层，不能只截最后一句。

2.4 条件

常见词：

只有……才……
只要……就……
除非……否则……
无论……都……

注意条件范围：

  • “只有 A 才 B”：A 是 B 的必要条件；
  • “只要 A 就 B”：A 是 B 的充分条件；
  • 选项把“只有”换成“只要”，逻辑已经改变。

2.5 并列

常见表现：

一方面……另一方面……
既……又……
同时、此外、也

并列结构通常需要概括共同主题，不能只抓其中一项。

2.6 对照与选择

常见词：

不是……而是……
与其……不如……
相较于、相比之下

作者通常借对照突出后一项，但仍要看主题是否完整。

3. 主旨概括题

3.1 常见问法

这段文字的主旨是
这段文字主要说明
对这段文字概括最准确的是
这段文字重在说明

3.2 作答顺序

  1. 找核心主体；
  2. 划出结构；
  3. 判断作者重点是在描述现象、分析原因、说明作用，还是提出对策；
  4. 自己先用一句话概括；
  5. 再选“主题一致、重点一致、范围准确”的选项。

3.3 常见结构

提出问题 → 分析问题 → 给出对策

一般重点在对策，但对策必须针对材料中的具体问题。

背景 → 问题 → 原因 → 因此应当采取某措施

优先选择包含“针对什么问题 + 应采取什么方向”的选项。

观点 → 解释/举例

第一句或前部提出观点，后面只负责说明。

重点是观点，不是例子的具体内容。

分述 → 总结

前面列举多个方面，末尾作总结。

重点通常是总结句。

总述 → 分述

首句提出中心，后面从多个角度展开。

重点通常是首句的总观点。

并列结构

多个方面地位相近，没有明确主次。

答案需要覆盖共同主题，不能只选其中一部分。

3.4 主旨题的最佳选项

通常同时满足：

主体正确 + 论述重点正确 + 覆盖全文 + 没有越界

“覆盖全文”不是字数越多越好。选项加入材料没有讨论的新内容，仍然错误。

4. 意图判断题

4.1 常见问法

这段文字意在说明
作者意在强调
作者通过这段文字想表达的是

4.2 主旨与意图的区别

  • 主旨：文段主要说了什么；
  • 意图：作者为什么要说这些，最想让读者接受什么观点或行动方向。

两者经常一致，但不是所有意图题都必须选对策。

4.3 什么时候优先考虑对策

材料具备以下链条时：

明确问题/风险 → 作者作负面评价 → 指向解决方向

如果选项提出与问题直接对应、不过度具体的对策，可以重点考虑。

4.4 什么时候不能硬选对策

  • 材料只在说明某个规律、价值或事实；
  • 所谓对策选项没有材料依据；
  • 对策比材料更具体，增加了部门、手段或目标；
  • 材料明确强调原因或意义，而非解决办法。

意图题的底线仍是材料证据，不能看到问题就自行开药方。

5. 标题选择题

5.1 标题的四个标准

  1. 主题准确：主体不能跑偏；
  2. 重点突出：体现材料最重要的信息；
  3. 覆盖恰当：不能只抓一个例子或局部；
  4. 表达适配：与新闻、科普、评论等材料风格相符。

5.2 不同材料的标题倾向

材料类型 标题倾向
新闻消息 主体 + 核心事件/变化
科普说明 说明对象 + 核心特点/机制
评论议论 观点、问题或倡议
故事寓言 核心寓意，不拘泥于情节

5.3 常见陷阱

  • 只概括开头背景；
  • 只描述最吸睛的例子；
  • 标题很生动，但缺少核心主体；
  • 使用“首次、全面、必然”等材料没有的强限定；
  • 上升到过于宏大的价值主题。

6. 细节判断题

6.1 常见问法

根据这段文字，下列说法正确的是
下列说法与原文相符的是
下列说法不正确的是

先圈出题干中的“正确”或“不正确”，防止选反。

6.2 作答方法

  1. 读选项，提取主体、关系和限定词；
  2. 回原文定位对应句；
  3. 对比主体、时间、范围、程度、条件和因果；
  4. 要求一一对应，不凭常识补充。

6.3 高频偷换

偷换方式 原文 错误选项
可能变必然 可能产生影响 必然产生影响
部分变全部 一些地区 所有地区
相对变绝对 更有利于 完全解决
条件被删除 在一定条件下有效 始终有效
主体被替换 研究对象 A 泛化为所有对象
时态被替换 正在探索 已经全面实现
因果倒置 A 导致 B B 导致 A
并列变因果 A 与 B 同时出现 A 导致 B

细节题不要求选项逐字复制原文，但同义改写不能改变逻辑边界。

7. 推断判断题

7.1 常见问法

从这段文字可以推出
根据文意可知
由此可以推断

7.2 推断原则

允许对材料信息作一步合理转换，不允许连续补充多个没有明说的前提。

优先选择：

  • 原文直接表达的同义转述；
  • 多个信息自然合并后的弱结论；
  • 不改变概率、范围和语气的结论。

警惕：

  • “可能”推成“一定”；
  • 个例推成普遍规律；
  • 相关推成因果；
  • 当前趋势推成最终结果；
  • 材料没有比较，却推出“最、首要、唯一”。

最稳的推断通常语气克制、离原文较近。

8. 词句理解与代词指代

8.1 词句理解

不能只解释字面意思，要结合上下文判断它在文段中的具体所指。

步骤：

  1. 找词句前后的解释、转折、因果或例子；
  2. 确认核心主体；
  3. 用材料中的直白语言替换；
  4. 排除把局部修辞无限拔高的选项。

8.2 代词指代

常见代词：

这、这些、这种、其、它、上述现象、这一做法

通常向前寻找内容完整、语法匹配、距离较近的对象，但不能只按“最近名词”机械判断。代词可能指代前面的整个事件或观点，而不是单个词。

检查：

  • 单复数是否一致；
  • 事物、行为或观点类型是否一致；
  • 代回原句后语义是否通顺。

9. 逻辑填空：先确定语境，再辨析词语

9.1 基本顺序

读完整句/段
→ 判断空格与上下文的逻辑关系
→ 预判空格需要表达的意思和感情色彩
→ 看选项
→ 用搭配、程度、语义侧重排除
→ 代回全文验证

不要看到空格就立即在四个词中凭熟悉度选择。

9.2 语境关系

关系 判断方法
解释对应 空格前后出现换言、解释或具体说明
相反相对 转折、对照、否定后需要相反或不同含义
并列对应 并列项语义方向、层级和句式应协调
递进对应 后一空通常程度更深或范围更广
因果对应 空格内容需与原因或结果逻辑相配
主题对应 所填词要服务于文段核心话题

9.3 实词辨析的六个角度

  1. 词义侧重：两个近义词分别强调什么；
  2. 适用对象：用于人、制度、文化、技术还是抽象关系；
  3. 程度轻重：改善、扭转、根除等程度不同；
  4. 感情色彩：褒义、贬义、中性；
  5. 语体色彩：口语、书面语、正式表达；
  6. 固定搭配：与宾语、介词、中心词是否自然搭配。

9.4 成语辨析的四步

  1. 先确认成语大意；
  2. 确认适用对象；
  3. 确认褒贬、程度和使用条件；
  4. 代回原句检查是否重复、矛盾或搭配不当。

不要只记成语中的单个字。很多成语的整体含义不能由字面直接拼出。

9.5 多空题怎么做

  • 先从差异最大、把握最高的一空入手；
  • 用这一空排除选项组合；
  • 再验证其余空，而不是因为第一空顺口就直接作答；
  • 两个空都“勉强能用”时，看哪个组合与全文逻辑更统一。

9.6 固定搭配的正确地位

固定搭配是证据之一，不是最高规则。若搭配成立但语境方向不符，仍然不能选。

优先级通常是：

语境逻辑 > 词义与对象 > 程度/褒贬 > 搭配习惯

10. 语句填空

10.1 横线在开头

通常承担：

  • 引出话题；
  • 总领下文；
  • 提出观点。

重点看后文共同讨论什么，不要选择只对应后文一句的选项。

10.2 横线在中间

通常承担：

  • 承上启下；
  • 转折过渡；
  • 解释或总结前文并引出后文。

必须同时与前后文衔接，只能承上或只能启下的选项不完整。

10.3 横线在结尾

通常承担：

  • 总结全文；
  • 得出结论；
  • 提出对策；
  • 呼应开头。

结尾选项不能突然引入全文未讨论的新主体。

10.4 三项检查

话题一致 + 逻辑一致 + 句式衔接

同时检查代词、关联词、主语是否能自然承接。

11. 语句排序

11.1 不要从头硬排

先看选项提供了哪些可能的首句和相邻组合，用确定性线索排除。

11.2 适合做首句的句子

  • 引入新概念；
  • 提出背景或话题；
  • 给出总观点；
  • 对某对象作首次完整介绍。

11.3 通常不适合做首句的句子

  • 含没有明确所指的“这、其、该、上述”；
  • 以“但是、因此、同时、也、还”等明显承接词开头；
  • 直接举例，但前文尚未提出观点；
  • 对某概念作进一步解释，但概念尚未出现。

“通常”不是绝对规则，仍要结合选项和完整语义。

11.4 高频捆绑线索

线索 常见顺序
指代 先出现具体对象，后出现代词
关联词 虽然在前，但是在后；因为在前，所以在后
重复词 前句末尾话题与后句开头衔接
时间 按事件发生或认识发展顺序
空间 按由远到近、由外到内等一致顺序
逻辑 提出观点 → 解释 → 举例 → 总结
概念 先引入/定义，后展开特点或作用

11.5 最后必须通读

找到候选顺序后完整通读，检查：

  • 主体是否突然变化；
  • 代词是否有明确指代；
  • 关联词是否成对；
  • 举例前是否已有观点；
  • 总结是否真的位于论述之后。

12. 下文推断题

12.1 核心原则

重点看文段最后一两句留下的“话题接口”，而不是重新概括全文。

12.2 常见衔接方向

  • 结尾提出新概念 → 下文解释概念；
  • 结尾提出问题 → 下文分析原因或给出解决办法；
  • 结尾提出观点 → 下文举例论证或具体展开；
  • 结尾列出多个方面中的第一项 → 下文继续其他方面。

12.3 排除已经讲过的内容

题目问的是“接下来”，选项如果只是重复前文已经充分说明的内容，一般不选。

也不能跳跃太远。例如结尾刚提出某技术的风险，下文更可能先解释风险表现或成因，而不是直接谈另一个行业的宏观战略。

13. 文章阅读

文章阅读本质上是多个片段题共享一篇材料。

13.1 建议顺序

  1. 快速浏览题目，知道会问哪些内容；
  2. 阅读文章时标出段落主题和转折/结论；
  3. 细节题回原段定位；
  4. 主旨、标题题最后做，利用前面形成的全文理解。

13.2 段落标签

每段只写几个字：

背景、问题、原因、机制、作用、案例、对策、结论

不要逐句做长笔记。

13.3 全文主旨

看各段之间的关系：

  • 多段是否共同说明同一对象的不同方面；
  • 某一段是否只是案例；
  • 结尾是否对前文作评价或提出对策；
  • 标题能否同时覆盖核心对象与全文重点。

14. 高频干扰项：看到选项先查边界

干扰类型 表现 检查方法
偷换主体 材料说 A，选项改成 A 所属的大类或相邻概念 B 圈出主语比较
扩大范围 部分、某些变成全部、普遍 查数量范围词
缩小范围 全文谈系统问题，选项只谈一个例子 看能否覆盖各段
程度加重 可能、有助于变成必然、彻底解决 圈出程度词
无中生有 观点正确但材料没说 要求指出原文依据
因果倒置 原文 A 导致 B，选项 B 导致 A 画箭头核对
强加因果 原文并列或相关，选项说导致 找因果词依据
条件丢失 删除时间、范围、前提条件 对照限定语
时态偷换 计划/正在变成已经完成 看时间和状态词
对策越界 材料只指出问题，选项增加具体手段 查手段是否有依据
例子当主旨 把论据说成全文中心 问例子在证明什么
主题过大 从具体问题拔高到社会、文明、人类 看材料是否支撑
主题过窄 只概括一句或一个方面 看是否遗漏并列内容
绝对表述 唯一、完全、均、任何、必然 原文无绝对依据则警惕

不是出现绝对词就一定错误。如果原文本身明确使用绝对表述，选项可以保留。判断标准永远是原文。

15. 看到问法，立刻执行什么

题目问法 第一反应 最后检查
主旨/中心 找主题和结构，自己先概括一句 是否覆盖全文、有无越界
意在强调 主旨基础上判断作者落脚点 不机械地见问题选对策
最适合做标题 核心主体 + 最重要信息 是否准确、简洁、适配文体

词句含义 看前后解释和全文主题 不只按字面解释
代词指代 向前找完整且匹配的对象 代回后是否通顺

16. 考场时间与止损

总计划给言语理解的初始时间盒为 25 分钟，但最终要按实际题量和个人数据调整。

16.1 单题启动期参考

题型 参考处理时间 到点仍纠结时
逻辑填空 35—50 秒 保留语境最匹配项，标记后走
短主旨/意图 40—60 秒 重新检查主题与结构，不反复品味措辞
长片段 60—80 秒 排除明显越界项，二选一标记后走
细节判断 50—75 秒 优先核对限定词，不全文重读多遍
语句填空 45—70 秒 检查横线前后衔接
语句排序 60—90 秒 用选项和确定捆绑排除，超时则走
下文推断 35—55 秒 只看尾部接口，排除已讲内容

这些不是死规定。训练初期允许更慢，目标是逐步形成结构识别，而不是为了达标乱猜。

16.2 两轮作答

第一轮：

  • 结构清晰、依据明确的题直接做；
  • 逻辑填空能确定两空以上时优先完成；
  • 长文段或排序题无切入口时标记离开。

第二轮只回收：

  • 已经二选一且知道分歧点的题；
  • 只需回原文核对一个限定词的题；
  • 排序中已有明确首句或捆绑关系的题。

不回收：

  • 四个成语都不认识；
  • 文段主题仍说不清；
  • 排序完全没有确定线索；
  • 只能靠“再读一遍也许有感觉”的题。

16.3 改答案规则

只有发现以下明确证据才改：

  • 原文定位错误；
  • 漏看否定词；
  • 主体或范围被偷换；
  • 找到确定的搭配或逻辑矛盾；
  • 原答案无法解释全文结构。

不能因为连续出现同一选项、某个选项看起来太简单或临交卷不安而改。

17. 专项训练顺序

第一阶段：不追速度，建立证据意识

建议顺序：

  1. 主旨概括；
  2. 意图判断；
  3. 细节判断；
  4. 语句填空和下文推断；
  5. 语句排序；
  6. 逻辑填空；
  7. 文章阅读。

主旨和细节能训练主题、结构和选项边界，是其他题型的基础。逻辑填空需要一定词语积累，但不要等“背完成语”再做题。

第二阶段：子题型限时

每组 10 题，记录：

  • 正确数；
  • 总用时和平均用时；
  • 主动放弃数；
  • 错因；
  • 哪些题虽然做对但没有证据。

第三阶段：混合训练

将逻辑填空、片段阅读和语句表达混合，训练题型切换。每 10 题记一次累计时间，观察是否后半段明显疲劳。

第四阶段：套卷中的时间盒

在完整行测中固定言语的起止节点。目标不是言语全部做完，而是：

  • 高把握题不因超时丢失；
  • 争议题不吞噬资料、判断的时间；
  • 完成量、正确率和耗时能够重复。

20. 词语和成语积累模板

只记录做题中真实遇到、影响判断的词，不从词典无目的抄写。

词语/成语 简明含义 侧重点 适用对象 褒贬/程度 常见搭配 易混词 最小例句

积累后必须做两件事：

  1. 用自己的话说出与易混词的差别；
  2. 隔一天不看笔记，完成一次回忆或相似题验证。

如果一个词只在极冷门题中出现一次，不必扩展成大篇笔记。

21. 一页考场速查版

一、所有题共用
先认题型 → 找核心主体 → 划结构 → 用证据审查选项
答案必须：主体对、重点对、范围对、语气对

二、主旨/意图
主旨 = 文段主要说什么
意图 = 作者最想强调什么
问题后不一定选对策；对策必须有材料依据
例子和数据通常是论据，先问它在证明什么

三、细节/推断
回原文定位：主体、时间、范围、程度、条件、因果
可能 ≠ 必然；部分 ≠ 全部；相关 ≠ 因果
推断选弱结论，不连续补前提

四、逻辑填空
先语境，后词义，再程度/褒贬/对象，最后看搭配
多空题从最有把握的一空排除，全部代回验证

五、语句表达
填句：看位置；中间必须承上启下
排序：看选项，找首句、指代、关联词、重复词和逻辑捆绑
下文：盯尾句接口，排除前文已讲和跳跃过远的内容

六、干扰项
偷换主体、扩大/缩小范围、程度加重、无中生有
因果倒置、强加因果、条件丢失、时态偷换
例子当主旨、主题过大/过窄、对策越界

七、止损
说不清文段主题 → 标记后走
二选一超过 20 秒 → 写清分歧点；仍无证据则走
排序 60—90 秒无确定线索 → 走
只有找到明确文本证据才改答案

最后只记一句：

言语题不选“最有道理”的，选“最符合原文主体、重点和边界”的。
