行测资料分析：速算技巧导航与选择顺序

目标：看到题目后，不是问“我会哪些技巧”，而是问“这道题最短的路径是什么”。
原则：先定性、再估算、后精算；先看选项差距，再决定保留几位。

1. 七个母技巧

技巧 最适合解决什么 识别信号 一句话动作
假设分配法 已知现期量和增长率，求基期量或增长量 A 和 r 已知，除法不好算 假设好算的基期量，配出增量，再分余量
百化分与份数法 基期量、增长量，尤其增长率接近常见分数 20%、16.7%、14.3%…… 把百分数化成分数，直接按份数拆
截位直除与误差控制 比重、平均数、倍数、基期量 本质是一个除法，选项首位或前两位不同 截取足够的有效数字后直接除
化除为乘 小增长率下的基期量 ` r
分数比较 比重、增速、平均数、倍数的大小比较 只问最大/最小，不要求具体值 先看方向，再用交叉相乘或差分
增长量比较 比较谁增加得最多 多组 A+r 比较 Ar/(1+r)，先定性后补算
十字交叉法 混合增长率、混合平均数、混合比重 整体由两个部分加总而成 整体居中，距离之比对应分母权重之比

2. 看到题型后的选择顺序

2.1 求基期量 B = A/(1+r)

r 接近常见分数？
├─ 是 → 百化分与份数法
└─ 否
   ├─ |r| 很小且选项差距大 → 化除为乘
   ├─ 能找到好算的整百/整千基期 → 假设分配
   └─ 选项很近、要高精度 → 截位直除

2.2 求增长量 Δ = Ar/(1+r)

r 接近 1/n？
├─ 是 → Δ ≈ A/(n+1)
└─ 否
   ├─ r 很小、选项差距大 → 先用 Ar 粗估
   ├─ 数据适合拆整百/整千 → 假设分配
   └─ 选项接近 → 精算 Ar/(1+r)

2.3 求比重、平均数或倍数

只问大小 → 分数比较
问具体值 → 截位直除
属于两个部分的混合值 → 十字交叉

2.4 求整体增长率

整体 = 部分1 + 部分2
├─ 选项可用范围排除 → 整体增速介于两部分增速之间
├─ 还需判断偏向 → 靠近基期量较大的部分
└─ 需要求权重或未知增速 → 十字交叉

3. 考场三级计算制度

第一级：定性

先判断：

  • 正负；
  • 大于还是小于；
  • 整体值落在哪个区间；
  • 数量级是一百、一千还是一万；
  • 分子增速和分母增速谁更大。

如果能唯一确定选项，到此停止。

第二级：粗算

使用：

  • 截前两三位；
  • 百化分；
  • Ar 近似增长量；
  • A(1-r) 近似基期量；
  • 现期量近似替代相近增速下的基期权重。

如果能拉开选项，到此停止。

第三级：精算

只在选项接近时使用：

  • 多保留一位；
  • 精确公式；
  • 交叉相乘；
  • 对近似结果做误差方向校正。

资料分析的计算精度由选项决定，不由完美主义决定。

4. 技巧之间的替换关系

同一道题经常有多条路径。例如已知现期量 720、增长率 20%，求增长量：

  • 公式：720 × 20% ÷ 1.2 = 120；
  • 份数法：20%=1/5，基期 : 增量 : 现期 = 5:1:6，增量为 720÷6=120；
  • 假设分配：假设基期 600，配增量 120，恰好合计 720。

三种方法数学上完全一致。考场只选当下最顺手的一种，不必刻意使用“高级技巧”。

5. 训练顺序

建议按以下顺序练：

  1. 百化分与份数法：建立百分数和份数的直觉；
  2. 截位直除：覆盖最多的普通计算题；
  3. 分数比较：解决大量“最大、最小”题；
  4. 增长量比较：形成定性优先意识；
  5. 假设分配：处理除法不顺的数据；
  6. 化除为乘：掌握小增长率的误差边界；
  7. 十字交叉：处理混合问题。

每种方法不要只看例题。至少连续做 10 道同类题，并记录两件事：

我为什么识别出它？
我在什么条件下不该用它？

6. 总口诀

先口径，后列式；先定性，后计算。
能范围，不求值；能估算，不精算。
百化分看份数，普通除法用直除。
小率化除为乘，难除尝试假设分配。
只比大小看分数，整体混合看十字。
选项若近，回归精确公式。
