行测资料分析速算技巧 01：假设分配法

用途：已知现期量和增长率，快速估算基期量或增长量。
核心：先把现期量的一大部分“分给”基期量，再按增长率配出增长量；剩余部分继续按同样的关系修正。
定位：这是基期量、增长量公式的口算展开，不是一个需要额外死记的新公式。

1. 它到底在“分配”什么

统一记号：

符号 含义
A 现期量
B 基期量
Δ 增长量
r 增长率，计算时写成小数

增长时有：

A = B + Δ
Δ = B × r

所以，现期量 A 本来就是由两部分拼成的：

现期量 = 基期量 + 增长量

而这两部分的比例是：

基期量 : 增长量 = 1 : r

例如增长率是 8%，每分配 100 给基期量，就要同时分配 8 给增长量，两者合计占用现期量 108。

基期量 100  →  增长量 8  →  现期量 108
基期量 850  →  增长量 68 →  现期量 918

这就是“假设分配”的本质：不用一上来硬算 A ÷ (1+r)，而是先找一组好算的 B₀ 和 B₀r，再修正余量。

2. 标准四步

已知现期量 A、增长率 r，求基期量 B 或增长量 Δ：

第一步：假设一个好算的基期量 B₀

B₀ 最好满足：

  • 大致接近真实基期量；
  • 乘以增长率容易口算；
  • 尽量一次分掉现期量的大部分。

增长时，真实基期量一定小于现期量，可先根据选项或 A ÷ (1+r) 的大致范围选择整百、整千数。

第二步：配出假设增长量

Δ₀ = B₀ × r

这一轮共分掉：

B₀ + Δ₀

第三步：求未分配量

E = A - (B₀ + Δ₀)
  • E > 0：第一轮分少了，要继续往基期量和增长量中加；
  • E < 0：第一轮分多了，要从两者中一起减；
  • E = 0：刚好分完，直接得到答案。

第四步：把余量按同一关系继续分配

余量仍然必须满足：

基期修正量 : 增长修正量 = 1 : r

若基期修正量为 x，则增长修正量为 xr，两者合计应等于 E：

x + xr = E
x = E ÷ (1+r)

考场不一定写这个除法。通常先估一个好算的 x，算出 xr，看二者之和与 E 还差多少，再微调一次即可。

最后：

B ≈ B₀ + x
Δ ≈ Δ₀ + xr

3. 例题一：求增长量，演示完整分配过程

题目

某地区 2025 年粮食产量为 936 万吨，同比增长 8%。2025 年比 2024 年约增加多少万吨？

A = 936
r = 8%
求 Δ

假设分配

先假设基期量为 850：

假设基期量：850
假设增长量：850 × 8% = 68
第一轮合计：850 + 68 = 918
未分配量：936 - 918 = 18

剩下的 18 也要分成“基期量 + 它的 8%”。先试着给基期量 17：

基期修正：17
增长修正：17 × 8% = 1.36
修正合计：18.36

比需要的 18 多了 0.36，把基期修正略微调小到约 16.67：

基期量 ≈ 850 + 16.67 = 866.67
增长量 ≈ 68 + 1.33 = 69.33

答案

约增加 69.3 万吨。

验算

866.67 × 8% ≈ 69.33
866.67 + 69.33 = 936

草稿纸最简写法

850 → 68 → 918
余18 ≈ 16.7 + 1.3
增量 ≈ 68 + 1.3 = 69.3

4. 例题二：增长率较大时怎样分

题目

某行业本期利润为 73.9 亿元，同比增长 70.3%。上期利润约为多少亿元？

A = 73.9
r = 70.3%
求 B

假设分配

先假设基期量为 40：

假设增长量：40 × 70.3% = 28.12
第一轮合计：40 + 28.12 = 68.12
未分配量：73.9 - 68.12 = 5.78

增长率较大，余量不能几乎全部分给基期。每给基期量 1，还要给增长量约 0.703，合计约 1.703。

试分 3.4 给基期量：

基期修正：3.4
增长修正：3.4 × 70.3% ≈ 2.39
修正合计：3.4 + 2.39 = 5.79

与余量 5.78 几乎相同，所以：

基期量 ≈ 40 + 3.4 = 43.4
增长量 ≈ 28.12 + 2.39 = 30.51

答案

上期利润约为 43.4 亿元。

这道题说明什么

增长率越大，增长量在现期量中占得越多。此时不能使用“余量几乎全给基期量”的粗略想法，必须按 1:r 明显分成两块。

5. 例题三：下降时不能照搬加法

下降 d 时，关系变为：

A = B - D
D = B × d

其中 D 是减少量，取正数。因此：

现期量 = 基期量 - 减少量

题目

某企业本期营业收入为 820 万元，同比下降 6%。上期营业收入约为多少万元？

A = 820
d = 6%
求 B

假设分配

先假设基期量为 850：

假设减少量：850 × 6% = 51
假设现期量：850 - 51 = 799
与实际现期量相差：820 - 799 = 21

基期量每增加 10，减少量也增加 0.6，现期量实际只增加：

10 - 0.6 = 9.4

要让现期量增加 21，基期量应增加约：

21 ÷ 0.94 ≈ 22.3

所以：

基期量 ≈ 850 + 22.3 = 872.3
减少量 ≈ 51 + 22.3 × 6% = 52.3

答案

上期营业收入约为 872.3 万元。

验算

872.3 - 872.3 × 6% ≈ 820

下降题的关键区别

增长：现期 = 基期 + 增长量
下降：现期 = 基期 - 减少量

下降题里，基期量向上修正时，减少量也向上修正；但二者在现期关系式中一加一减，不能再把它们相加凑现期量。

6. 例题四：求两个基期量的差

题目

本期甲行业产值为 1240 亿元，同比增长 12%；乙行业产值为 1080 亿元，同比增长 8%。上期甲行业产值比乙行业约多多少亿元？

甲行业

假设甲的基期量为 1100：

增长量：1100 × 12% = 132
合计：1100 + 132 = 1232
未分配量：1240 - 1232 = 8

8 中约有 7.14 属于基期量，约有 0.86 属于增长量：

甲的基期量 ≈ 1100 + 7.14 = 1107.14

乙行业

1000 + 1000 × 8% = 1080

所以乙的基期量正好是 1000。

作差

1107.14 - 1000 = 107.14

答案

上期甲行业产值比乙行业约多 107 亿元。

题型提醒

遇到“基期和、基期差、基期倍数”，先分别用假设分配求出各自基期量，再按题目要求相加、相减或相除。不要直接拿两个现期量作差后统一除以某个增长率，因为两个对象的增长率可能不同。

7. 为什么这种方法可行

假设的基期量为 B₀，与真实基期量相差 x：

B = B₀ + x

那么真实增长量就是：

Δ = B × r
  = B₀r + xr

真实现期量为：

A = B + Δ
  = (B₀ + B₀r) + (x + xr)

这说明：第一轮假设之后剩下的误差，仍然由一份基期修正量 x 和一份增长修正量 xr 组成，比例仍然是 1:r。所以可以一轮一轮继续分配，直到精度足够。

它与精确公式完全一致：

x + xr = E
x = E ÷ (1+r)

假设分配法只是把除法变成了更适合草稿纸和口算的“先分大块、再补小块”。

8. 什么时候优先使用

适合：

  • 已知现期量和增长率，求基期量或增长量；
  • 选项有一定差距，只需算到能区分选项；
  • 能迅速找到整百、整千等好算的假设基期量；
  • 求两个基期量之和、之差时，分别分配比连续做复杂除法更顺手；
  • 增长率不是特别适合直接化成简单分数。

不一定优先：

  • 增长率接近 1/2、1/3、1/4、1/5、1/8 等简单分数，直接用份数法更快；
  • 增长率很小、选项差距又大，只求增长量时可先用 A × r 粗估；
  • 选项极近，需要较高精度，直除或精确公式更稳；
  • 第一轮很难找到好算且接近的假设值，强行分配反而增加步骤。

经验上，小增长率更容易一两轮完成；大增长率也能使用，但余量必须明显分给“基期量”和“增长量”两部分，不能把余量几乎全塞给基期量。这里没有必须死记的增长率界线，应以数据是否好算、选项差距是否允许为准。

9. 与相似方法的区别

方法 主要用途 核心动作
假设分配法 已知现期量、增长率，求基期量或增长量 把现期量拆成基期量和增长量
特殊分数法/份数法 增长率接近常见分数 把 r 化成 m/n，按份数计算
直除法 求基期量、比重、平均数等 对分子分母截位后直接除
十字交叉法 两部分混合得到整体增长率、浓度、均价等 利用整体值与两个部分值的距离求权重比

假设分配法不是混合增长率的十字交叉法。前者拆的是同一个指标的“基期量和增长量”，后者比较的是两个部分对整体的加权作用。

10. 考场草稿模板

增长

A，r，求B/Δ

假设B₀ = ______
配Δ₀ = B₀r = ______
已分 = B₀ + Δ₀ = ______
余量E = A - 已分 = ______
再分：x + xr ≈ E

B ≈ B₀ + x
Δ ≈ Δ₀ + xr

下降

A，下降d，求B/D

假设B₀ = ______
配D₀ = B₀d = ______
假设现期 = B₀ - D₀ = ______
与实际A的差 = ______
再调：x - xd ≈ 差值

B ≈ B₀ + x
D ≈ D₀ + xd

11. 高频错误

  • 把增长题写成 现期量 = 基期量 - 增长量；
  • 把下降题的减少量与基期量相加；
  • 第一轮只假设基期量，却忘记同步配出 B₀r；
  • 修正基期量后，没有同步修正增长量或减少量；
  • 增长率较大时，仍把全部余量近似当作基期修正量；
  • 为追求小数点后多位反复修正，忽略选项其实已经可以区分；
  • 两个对象增长率不同，却先拿现期量作差再统一还原基期；
  • 忘记把百分数化为小数，如把 8% 当成 8。

12. 自测题

题 1

某产品本期销售额为 742 万元，同比增长 6%。上期销售额和本期增长量分别约为多少？

题 2

某景区本期接待游客 845 万人次，同比增长 13%。本期约增加多少万人次？

题 3

某商品本期出口额为 846 万元，同比下降 6%。上期出口额和减少量分别约为多少？

展开答案
  1. 假设基期量为 700，增长量为 42，合计正好是 742。所以上期为 700 万元，本期增长 42 万元。
  2. 假设基期量为 750，增长量为 97.5，合计为 847.5，比实际多 2.5。向下修正后，基期量约为 747.8，增长量约为 97.2 万人次。
  3. 假设基期量为 900，减少量为 54，900 - 54 = 846。所以上期为 900 万元，减少 54 万元。

13. 一句话记忆

增长：先假设基期，再按增长率配增量，两者相加凑现期；余量继续按 1:r 分。
下降：先假设基期，再按下降率配减量，两者相减凑现期；修正时注意一加一减。

最后提醒：假设只是选择一个好算的起点，比例关系必须始终真实。算到足以排除选项就停，不必追求无意义的精确。
