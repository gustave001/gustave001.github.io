行测资料分析速算技巧 07：十字交叉与混合增长率

核心用途：整体由两个部分相加而成，已知其中若干增长率、平均数或比重，快速判断整体值、权重比或未知部分值。
最重要的前提：先确认是“加总型整体”，再找真正的权重分母。

1. 混合问题的统一结构

若两个部分的比值分别为 r₁、r₂，对应分母权重为 B₁、B₂，整体比值为 r：

r = (B₁r₁ + B₂r₂)/(B₁+B₂)

因此整体值必有两个性质：

  1. r 一定介于 r₁ 和 r₂ 之间；
  2. r 更靠近分母权重较大的那一方。

这不仅适用于增长率，也适用于平均数、浓度、比重等加权平均结构。

2. 十字交叉关系

假设：

r₁ > r > r₂

则：

B₁/B₂ = (r-r₂)/(r₁-r)

可以画成：

部分1：r₁       r-r₂   ← 对应 B₁
          \     /
           整体r
          /     \
部分2：r₂       r₁-r   ← 对应 B₂

记忆：交叉作差，横向对应权重。

3. 例题一：由增长率求基期量之比

甲、乙两部分同比增长率分别为 18% 和 6%，合计同比增长 10%。甲、乙基期量之比是多少？

整体增长率 10% 介于两者之间。十字交叉：

甲基期量/乙基期量
= (10%-6%)/(18%-10%)
= 4%/8%
= 1/2

所以甲、乙基期量之比为 1:2。

验证：

(1×18% + 2×6%)/(1+2) = 10%

4. 例题二：已知权重求未知增速

甲、乙基期量之比为 2:3。甲增长 15%，合计增长 9%，求乙的增长率。

设乙增长率为 x：

(2×15% + 3x)/(2+3) = 9%
30% + 3x = 45%
x = 5%

也可用十字距离理解：整体 9% 更靠近乙的 5%，因为乙基期量更大。

5. 例题三：只用范围秒杀

某地区城镇人口增长 8%，乡村人口下降 2%，总人口增长率可能是：

A. -5%  B. 1%  C. 9%  D. 13%

总人口是城镇人口与乡村人口之和，所以总增速一定介于 -2% 和 8% 之间。只有 1% 符合，直接选择 B。

这类题根本不需要画十字。

6. 增长率的权重为什么是基期量

各部分增长量为：

Δ₁ = B₁r₁
Δ₂ = B₂r₂

整体增长率：

r = (Δ₁+Δ₂)/(B₁+B₂)
  = (B₁r₁+B₂r₂)/(B₁+B₂)

所以增长率混合的权重是基期量，不是现期量。

当两部分增长率都不大、也比较接近时，可以用现期量之比近似基期量之比；但选项接近或增长率差异大时，必须还原基期量。

7. 不止能混合增长率

7.1 混合平均数

甲组平均数 80，乙组平均数 70，合计平均数 76：

甲人数/乙人数
= (76-70)/(80-76)
= 6/4
= 3/2

平均数的权重是人数。

7.2 混合比重

甲地区某类人口占比 60%，乙地区占比 40%，两地合计占比 45%：

甲总人口/乙总人口
= (45%-40%)/(60%-45%)
= 5/15
= 1/3

比重的权重是各地区的整体量，不是该类人口数。

统一规律

混合谁，权重就是谁的分母。
混合指标 权重分母
增长率 基期量
平均数 份数/人数
比重 各部分的整体量
单价 数量
速度 通常不能直接套，需先看时间或路程结构

8. 时间混合也可以用

若：

1—5月累计量 + 6月当月量 = 上半年累计量

对应的同比增长率也构成混合增长率，权重分别是上年同期的 1—5月累计量 和 6月当月量。

但必须先把时间段拆对。不能把“1—6月累计”与“6月当月”当成互不重叠的两个部分直接混合。

9. 不能使用的情形

  • 整体不是两个部分的和，而是 A-B；
  • 两个部分存在重叠，不能相加得到整体；
  • 口径、时间或单位不一致；
  • 把现期量直接当作增长率的精确权重；
  • 三个及以上部分却在没有合并信息时强行画一个十字；
  • 速度、生产率等关系未必是简单加权平均，没确认分母就套公式。

若整体为差值，应回到：

整体增长量 = A的增长量 - B的增长量
整体增长率 = 整体增长量 ÷ 整体基期量

10. 草稿模板

先确认：整体 = 部分1 + 部分2
再确认：混合指标的分母权重是什么

r1 > r > r2
B1/B2 = (r-r2)/(r1-r)

先用“居中”排除；
再用“靠近大权重”判断；
仍不够才十字计算。
