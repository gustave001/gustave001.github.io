HTML 知识站维护说明

从本次迁移开始，personal/exam/site/ 中的 HTML 是考试资料唯一维护源。后续新增、修改、插图、纠错和目录调整都直接维护 HTML；不再回写、同步或新增考试内容 Markdown。原 Markdown 文件仅作为迁移前的历史资料保留。

唯一来源规则：如果 HTML 与旧 Markdown 内容不一致，一律以 HTML 为准。维护任务不得为了“同步”而修改旧 Markdown，也不得先写 Markdown 再生成 HTML。

目录约定

site/
├── index.html              # 网站首页
├── assets/
│   ├── styles.css          # 全站视觉与响应式布局
│   └── site.js             # 目录、返回、面包屑、前后翻页
└── pages/                  # 与原资料目录对应的正文 HTML
    ├── 言语理解/技巧方法/
    ├── 数量关系/题型方法/
    └── 资料分析/速算技巧/

以后新增或修改内容

  1. 直接打开 site/pages/ 中对应的 HTML 修改正文。
  2. 新增专题时，复制一个同层页面，保留外层页面骨架，只替换 <article class="prose"> 内的内容。
  3. 在 assets/site.js 的 pages 数组中添加标题和路径，侧边目录、面包屑与前后翻页会自动出现。
  4. 共享颜色、字号和移动端布局统一修改 assets/styles.css。
  5. 不要修改或新增考试内容 Markdown，也不要再次运行 Markdown 转 HTML 的批量迁移流程覆盖现有网页。

插图建议

公式关系、几何图形、集合关系和时间线优先使用内嵌 SVG。它可以直接写进 HTML，不依赖外部图片，离线可用且放大不失真。

<figure class="diagram-card">
  <svg viewBox="0 0 400 240" role="img" aria-label="图示说明">…</svg>
  <figcaption>图示标题</figcaption>
</figure>

照片或扫描图再使用 PNG/JPEG，统一放在 site/assets/images/，正文使用相对路径。

打开方式

可以直接双击 site/index.html。为了让浏览器历史记录、中文路径与调试行为更稳定，也可以在 personal/exam/site 目录启动静态服务器：

python3 -m http.server 4173

然后访问 http://127.0.0.1:4173/。

维护原则

  • 一页只解决一组高度相关的问题；
  • 每页至少说明识别信号、操作步骤、例题、易错点和止损条件；
  • 图示必须服务于关系理解，不为装饰而添加；
  • 任何近似方法都写清误差方向与禁用条件；
  • 新页面同时加入全站目录，避免成为孤立文件。
